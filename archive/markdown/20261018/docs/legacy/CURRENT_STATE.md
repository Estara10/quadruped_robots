## 一句话状态

仓库已有可运行的 Go2+MuJoCo+ROS 2 策略链、三类部署模型、单阈值切换候选、D 类组合切换候选和结构化运行记录基础，但开题报告要求的 A/B/C/D 四组独立机制、正式障碍终局判定、成套配对实验和低速实机闭环尚未完成。

## FACT：已存在并有证据支持

### 模型与控制链

- Agile、RA Value、Recovery TorchScript 模型已纳入 `artifacts/manifest.yaml`，包含文件哈希和已知来源边界。
- ROS 2 控制器已能加载三模型，并在 MuJoCo 运行 Agile/RA/Recovery 链。
- 当前配置 `decimation=4`，控制器更新率 200 Hz；已接受的历史 P1-08 证据显示策略/RA 实际频率约 49.97 Hz。
- 控制器顺序为 FR、FL、RR、RL；策略顺序和转换边界已有代码/文档资产，但仍应随正式实验版本冻结。

### 切换逻辑

- `paper_faithful_switch` 实现 `RA >= entry_threshold` 进入 Recovery、否则 Agile，无滞回、无保持；它是提案 A 组的逻辑候选。
- `stabilized_switch` 同时使用不同进入/退出阈值与 Recovery 保持步数；它是 legacy 的 D 类候选，不是已经验收的提案 D 组。
- 现有离线单元测试覆盖上述两个 legacy 模式的真值表。

### 可观测性与实验基础

- 运行时帧包含单调时间、session/step、RA、policy state、位姿、速度、ray2d、动作、关节目标和力矩。
- 历史 P1-02/P1-08/P1-09 形成了 schema、记录器、HUD、运行绑定和进程清理等可复用基础。
- 碰撞 v2 桥接链和部分正式记录工具已存在，但尚未形成论文实验所需的完整终局权威。
- 已存在固定场景/种子、配置哈希和配对运行相关工具，可选择性复用。

### 场景与感知资产

- 仓库存在历史 `scene_test1`—`scene_test5` 与多场景工具，但旧审计表明其正式支持状态不一致。
- `scene_ppt_sparse.xml`、`scene_ppt_medium.xml`、`scene_ppt_dense.xml` 已存在，可作为稀疏/中等/密集场景候选；其 README 明确它们目前只是视觉演示资产。

### 实机基础

- 因此当前只可声明“具备部分实机安全与部署基础”，不能声明实机安全运动系统完成。

## 技术债与已知风险

1. **最高风险：机制混淆。** legacy `stabilized_switch` 同时改变阈值相等性、滞回和保持，不能直接支撑 B/C/D 因果比较。
2. **时间语义风险。** 代码/注释存在 125 Hz 与实际约 50 Hz 不一致，按步计时会改变保持时长。
3. **终局权威风险。** 碰撞、跌倒、到达、超时未在同一正式链中闭合，会使安全和成功率结论无效。
4. **场景有效性风险。** 现有演示/历史场景不能自动升级为正式实验场景。
5. **感知与 Sim-to-Real 风险。** 实机感知、时效、标定和 fail-safe 尚未验证。
6. **证据完整性风险。** 历史 P1-10 有运行产物丢失事件；相关 pair 只能作为 legacy 事故记录，不能用于验收。
7. **范围膨胀风险。** exact float replay、平台扩展或重新训练可能消耗时间但不直接回答开题问题。
