## 7. 本轮开始前固定评分

使用用户确认的权重，**归一化常量不因M2成绩重新拟合**：

| 分项 | 逐run分数 | 权重 |
|---|---|---:|
| 到达 | ARRIVED=1，其他合法任务终局=0 | 0.40 |
| 无终止性碰撞 | 任务窗碰撞False=1，True=0，UNKNOWN不补零 | 0.30 |
| 效率 | ARRIVED时`max(0, 1−任务到达时间/20)`；未到达=0 | 0.20 |
| 稳定性 | `1 / (1 + f/257.8)`；f为每分钟有效任务时间的0.5秒短反向切换频率 | 0.10 |

逐run总分=`100×(0.40×到达分+0.30×无碰撞分+0.20×效率分+0.10×稳定性分)`。

每图每档先平均3次分数，再对6图等权平均。稳定性先逐run变换，再平均；不能把阈值总体平均频率代入非线性公式。保留未四舍五入的中间值，显示时才舍入。到达时间略超20秒的离散终止周期效率取0，原ARRIVED和真实时长保留。

评分分母遵循有效任务结果，INVALID、未运行和工程attempt单列。缺少碰撞结论、任务计时或完整短反向频率时，该run总分为UNKNOWN；不得删除缺失run后冒充完整3次/图或18次/档成绩。各档都须报告已运行、有效、完整可评分及UNKNOWN数量；覆盖不齐时只给明确标注的部分结果，不能强行给完整排名。

碰撞口径为任务窗口终止性非足端障碍碰撞。足端撞击、跌倒True/UNKNOWN、越界、保护触发、Recovery占用和收尾接触继续单列：**综合分不等于安全分，也不自动证明安全约束满足**。本轮不偷偷增加跌倒罚分或为分高者放宽安全门。未到达效率0与到达分共同惩罚失败，是既定设计；不再另加超时扣分。
