## 本轮规则

诊断参数 E=-0.05、X=-0.08、H=0.30 仿真秒；不是正式论文参数。

| 当前模式 | 有效决策条件 | 下一模式与当周期动作 |
|---|---|---|
| Agile | RA>=E，且 D 时钟有效 | Recovery，保存本次进入时间 |
| Agile | RA<E | Agile |
| Recovery | elapsed<H | Recovery，即使 RA<X 也不提前退出 |
| Recovery | elapsed>=H，且 RA>=X | Recovery，不重启保持 |
| Recovery | elapsed>=H，且 RA<X | Agile，当周期退出 |

- RA==E 时进入；RA==X 时不退出；elapsed==H 时已到期。
- D 与 B 共用 X 和比较符，与 C 共用 H、时钟和起算规则。只有新的 Agile→Recovery 边沿起算；Recovery 中风险再升高不重启。
- 起点为模式决定周期的当前 run MuJoCo 仿真时间，保持约束模式驻留，不冒充命令实际消费后的持续时间。
- 无效时钟时 D 不执行 RA 驱动转换；回退、来源或 segment 异常不得伪造到期、重启或延长起点。复用 C 的生产语义，新 run/RL session 清除旧模式、计时和缓存。
- 暂停不消耗仿真保持时间；STALE 不自动解释成暂停。无效 RA、既有安全故障和 run 终局保持优先，不关闭检查。
- A/B 不因 D 的时钟需求新增切换限制；A/B/C 已验证的规则不回退。

- 复用 B 的退出阈值和 C 的生产计时，不建设另一套 D 专用计时器或通用框架。

### 2. 记录、面板与分析

- 让配置来源、帧、reader、recorder、诊断器、面板及分析器识别 D；尽量复用 v3 字段，只有确有需要才改格式，并同步读写端及保留历史语义。

- 面板只读显示 D、双阈值与保持剩余/到期/无效状态，不改变决策。
- 审计每次正常退出是否同时满足 elapsed>=H 与 RA<X，单独标记终局截断。缺帧、缺起点/终点或无效时间导致不能判断时记不完整/UNKNOWN，不插值。
