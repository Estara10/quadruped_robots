## 1. 首个策略周期的实测初态

- 优先在 controller 首个有效且活跃的策略决策周期保存当周期实际读取的12个关节位置/速度、机器人姿态和可取得的速度，不临时启动异步订阅代替该周期状态。
- 保存 run/session/cycle、仿真时间、时钟有效性、具名关节对应和单位。位置/速度必须是实测输入，不是输出目标、默认配置或 XML keyframe。
- 同周期指同一次控制器观测采样，不能声称传感器底层物理采样完全同步；来源本身异步时记录可取得的时间偏差或 UNKNOWN。
- 复用现有记录链，必要时最小扩展版本并同步发布、reader、recorder、HUD及分析，保留旧格式语义。也可采用明确周期关联的轻量一次性初态记录，避免无必要扩张全部帧。
- ROS joint-state 样本保留为辅助信息；不补造 S6-01 A/B 初态。
- 完整记录不等于四组初态一致；不为此建设确定性重放。正式初态控制方案另行确定。
- 以首个有效活跃策略周期作为本次主要任务起点，记录规则并保留旧0.10m位移起点辅助指标。时间无效时不得静默挪动边界以取得好结果。

## 2. 碰撞覆盖诊断与最小修正

- 沿 MuJoCo 物理步发布器、累计计数/历史、快照reader、记录器及分析器追踪覆盖判定。
- 区分物理步遗漏、历史溢出、未分类接触、无效样本、run/source变化、采样稀疏及分析器误判。
- 采集快照不连续不必然代表物理步累计遗漏。只有发布器累计机制、历史容量、来源和窗口边界提供直接依据时，才能用较稀疏快照证明窗口完整；不得直接删除连续性检查或把未知改为零。
- 边界快照保存事件累计/历史及对应物理步与时间，说明窗口内事件如何归属。跨起点/终点的episode、累计边界不对齐和溢出按可证明范围裁切或UNKNOWN，不伪造精确持续时间。
- 足端轻微接触、按 Fxy>2*abs(Fz)+10N 判定的足端撞击、非足端终止碰撞继续分开；足端不因此终止。
- 检测到的事件有直接证据；无事件的否定结论必须有窗口覆盖依据。无法合理修复的缺口说明对后续实验的影响。

## 3. 跌倒判断与窗口语义

- 明确现有高度、倾角、持续时间及参考系/单位，核对 tracker、reader和分析器一致性，不为减少UNKNOWN任意改阈值。
- 区分已确认跌倒、短暂候选后恢复、终局时仍未确认、历史溢出和数据不足；完整覆盖且候选恢复的含义需按现有判据解释，未闭合候选不能凭猜测判未跌倒。
- 启动阶段、任务阶段、站立观察分别报告；事件跨边界时保留持续状态，避免把启动异常误算或漏算运动期异常。
- 不声称本轮诊断判据已成为正式或实机参数。若现有阈值本身需要研究性修改，记录建议并交Director决定。
