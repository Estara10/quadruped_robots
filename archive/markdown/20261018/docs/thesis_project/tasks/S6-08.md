# S6-08：随机静态障碍地图生成与通路核验

**状态：COMPLETE（Director 有条件通过）。** 通过范围：可复现地图生成器、六张开发样例、几何检查、生产场景接入及两次短诊断。六张样例仅属开发样例，不是最终 60 张地图，也不进入留出测试集。

保留限制：密度档位存在重叠；保守机器人通行包络未经过步态实测；运行存在策略周期/仿真时钟缺口；中等和密集场景各仅一次诊断，不能据此得出成功率或性能结论。当前没有已授权的 Active Task。建议下一步规划最终地图生成规则、开发/留出划分及批量生成；本任务收尾不创建或启动该任务。

## 目标

建立可复现的随机静态障碍地图生成器，生成稀疏、中等、密集各两张样例，并接入现有 `--scene`、MuJoCo、射线、碰撞、场景身份、记录和分析链。参考路径只用于几何检查和预览，不传入机器人策略。六张样例仅属开发样例，不进入留出测试集。

## 生成要求

- 默认起点 `(0,0)`、目标 `(7,0)`，保持现有 Go2、平地、模型接口、控制链、到达半径及物理参数。
- 障碍可由箱体、圆柱和旋转长条组成；密度由占地比例、间距和可行通道宽度共同定义。
- 每张记录 scene ID、生成器版本、生成种子、密度、边界、起终点、障碍几何参数、XML、俯视图、通路检查结果/参考路径/最窄通道，以及起终点直线阻挡状态。生成种子与运行种子分开。
- 起点及目标留有净空；障碍不越界或非预期重叠；射线可见性与障碍高度相符。六图至少四图有直线阻挡且保留可绕行通道。
- 使用实际旋转箱体投影与圆柱轮廓进行通路检查，按 Go2 身体/足端包络和有依据的余量膨胀障碍；说明分辨率、余量来源和最窄通道定义。有限次重采样；无路时明确拒绝。
- 生成结果应由相同配置和种子确定性复现。保留现有五张地图、身份与原始数据，不覆盖历史资产。

## 核验与诊断

先做必要离线检查：种子复现、边界/净空/重叠/直线阻挡、通路连通与通行包络、无通路拒绝；以生产加载路径核对六张 XML、射线和碰撞集合及场景身份；检查现有场景功能未回退。

离线核验通过后，最多两次普通 A 组短诊断：中等一张、密集一张。沿用当前 A 参数、模型、启动增益交接、安全规则、运行上限与到达后站立观察，运行前完成来源及显示预检。合法碰撞、跌倒、超时或安全终止均保留，不为到达而重跑；基础设施失败则停止后续场景。每次运行后清理并核对本次 MuJoCo、controller、ROS、RViz、采集器及辅助进程，不影响其他会话。
