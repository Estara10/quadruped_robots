## 二、毕业设计最终目标与研究边界

课题：**面向复杂障碍环境的四足机器人风险驱动安全策略切换方法研究**。

依照仓库对已通过开题报告的任务分解，最终需要：

- 在Unitree Go2、MuJoCo和ROS 2平台上完成风险驱动的正常运动/恢复策略切换；
- 分别检验双阈值滞回、Recovery最小保持及二者组合的作用；
- 用正式A/B/C/D对照回答切换稳定性、安全响应、任务完成和运动效率之间的权衡；
- 完成失败案例及不确定性分析，形成论文表格、图、方法和复现资料；
- 安全准备通过后做代表性、低速、受监控的实机验证。目前实机仍为NO-GO。

研究重点是**切换机制**。不以重新训练出更强的避障策略、解决任意迷宫或超越原作者所有性能为当前主任务。近期工作复用既有Agile/Recovery/RA模型，未开展新的模型训练。

## 三、系统与A/B/C/D是什么

### 1. 运行结构

机器人状态与前方障碍输入 → Agile运动策略与RA风险评估 → 切换器 → Agile或Recovery动作 → 控制器 → MuJoCo → 记录与分析。

- Agile负责常规运动，Recovery负责风险情况下的恢复/避障动作。
- RA数值越高表示风险方向越高，**不是经过校准的碰撞概率**。
- 当前仿真障碍观测为几何射线：前方约90°内11条射线、范围约0.1–6m；不等同真实三维激光雷达、深度相机或全向感知。
- Recovery actor本身不直接接收这组射线；障碍输入通过RA及相关恢复流程起作用。
- 策略/RA约50Hz，控制约200Hz；实际频率由各run记录。
- 当前长时间预实验使用隐藏GLFW窗口并关闭RViz；仍依赖DISPLAY/OpenGL，不是真正不依赖显示的headless。

### 2. 四组设计

| 组别 | 滞回 | 最小保持 | 当前研究设置 |
|---|---|---|---|
| A | 无 | 无 | RA≥−0.05进入Recovery，RA<−0.05退出 |
| B | 有 | 无 | RA≥−0.05进入，RA<−0.10退出 |
| C | 无 | 有 | 单阈值−0.05，Recovery至少保持H；当前候选H=0.20s |
| D | 有 | 有 | E=−0.05、X=−0.10，加相同H=0.20s |

H按MuJoCo**仿真秒**计时，从Agile进入Recovery时起算。到期还须满足对应风险退出条件；Recovery内风险再次升高不重置起点；安全停止优先。

主要比较为B−A、C−A、D−B、D−C。正式机制对照应让B/D共用X、C/D共用H。若只为D另选H，就引入额外参数差异，需要另设共同参数的对照，不能直接解释成两个机制的独立作用。

### 3. 任务与事件规则

- 当前开发实验多用起点约(0,0)、目标(7.5,0)m、到达半径0.5m。
- 常用上限20仿真秒/120墙钟秒；较早历史诊断存在不同设置，不能不加区分合并。
- 正常到达后受控停止并保持站立，近期默认观察2仿真秒；早期部分批次为5秒。
- 足端轻微接触与足端撞击单独记录，不按非足端碰撞直接终止；非足端障碍碰撞可终止任务。
- 当前跌倒规则：base高度低于0.22m或绝对roll/pitch超过60°，持续0.30有效仿真秒确认。它是本项目规则，不能说成ABS论文的统一定义。
- ARRIVED是目标判据成立，VALID是记录/来源核验通过，二者都不自动等于安全成功。

## 七、评价方法及为何没有只按分数选参数

### 主决策

在新批次前固定开发工程规则：相对当批参考，到达下降≤5个百分点、非足端碰撞上升≤5个百分点；确认跌倒单独审阅；UNKNOWN单列并做情景分析；短反向频率下降20%作实用改善参考。再看Recovery占用、超时、到达效率、足端撞击与逐图退化，优先较小的有效滞回/保持。

这些容忍度是工程选择，不是文献统一阈值或已被证明的统计非劣效界限。总体过线不能抹去m06等明显退化；未显著不等于等效。

### 辅助评分

历史上采用过40%到达、30%安全分量、20%效率、10%切换稳定性的综合分，存在完成任务重复奖励、失败但无碰撞仍得部分分等局限。该评分是项目自行制定，不是ABS原作者指标权重。

首400项的评分属于事后分析；不同批次的安全分量细节还须在引用时核对，不能仅凭同名“辅助分”跨批排名。近期参数选择以约束、分层和权衡为主，综合分不负责宣布赢家。

### 统计口径

- 地图内先汇总重复，再地图等权；按easy/middle/difficult分层。
- 部分批次使用分层地图簇bootstrap报告区间，不把大量episode当成大量独立地图。
- 共同到达时间只反映选择性子集，不推论总体速度提升。
- 有目的选图、小重复和初态差异使结论只能定位为开发选参。
