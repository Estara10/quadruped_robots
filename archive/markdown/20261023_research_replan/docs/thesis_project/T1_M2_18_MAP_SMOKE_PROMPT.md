## 无窗口后台要求

- 所有实际场景使用已有隐藏GLFW生产模式，ROS传入`start_rviz:=false`，不启动RViz、不弹MuJoCo窗口、不依赖键盘。`--no-window`不是只有终端回显，要核对实际子命令和本次日志。
- 隐藏GLFW仍依赖DISPLAY/OpenGL，不能宣称真正无X11的headless。预检与整个批次使用同一获准执行环境；按需正规申请临时沙箱外X11/DRM访问，沿用现有`:0`与`/run/user/1000/gdm/Xauthority`。不改全局授权、驱动或桌面设置，不静默回退到可视窗口。
- 保持原生产PhysicsLoop、射线、碰撞/跌倒/越界累计、实时同步、频率与安全门；不为加快批次采用全速物理循环或替代probe运行策略。
- 不拍图、不录视频，保留原始策略与物理安全记录、context、terminal、process facts、cycle0初态和分析结果。
- 使用可靠长任务会话并保存runner PID、日志、进度与退出状态。串行执行，不能启动后不监控或提前声称完成。用户请求停止时完成当前安全清理并保留未完成状态，不留下后台孤立子进程。

## 失败、补做和预算

- 基础18次实际场景；另最多2次已定位并修复的基础设施失败补做，总实际场景最多20次，每项最多启动2次。
- 合法到达、碰撞、跌倒、仿真时限/任务墙钟终局均保留，清理完成后继续下一图；不能因为“地图看起来难”或成绩差而重跑、改图或删图。
- 系统安全veto、来源/记录冲突、清理无法确认等，先停止定位；仅允许不改变研究/安全语义的最小修正及定向核验后，按原额度补做。若同项补做仍无效、同一故障反复、需更改安全/控制语义或额度用尽，结束并报告，不无限重试。
