## 3. 运行前固定的评价规则

规则参考既有开发结果制定，必须先写入冻结方法再运行；不是文献规定、不是未知数据上的正式预注册，也不事后改规则制造获胜者。

### 3.1 质量与安全解释先行

- 保留非足端障碍碰撞、确认跌倒、足端撞击、base_link越界、安全中止及安全UNKNOWN，不能用综合分抵消。
- 某档出现任务期确认跌倒，不进入自动代表值推荐，单独提交原因与不确定性供审阅；不由单次事件宣布真实风险概率。
- UNKNOWN不补成False。碰撞/到达比较分别给出有利与不利情景；两种情景改变候选资格时标为“证据不足”，不算已通过。
- VALID只表示来源和记录有效，不等于安全成功。基于base_link的界内结论不升级为整机足迹界内。

### 3.2 任务表现的开发性容忍度

操作参考为**本轮新运行**的X=−0.07，不用旧批次参考成绩。各地图等权：

- 到达比例相对参考下降不超过5个百分点。
- 非足端障碍碰撞比例相对参考上升不超过5个百分点。
- 超时、保护和UNKNOWN独立展示，不额外隐含加权。

这两个5个百分点是工程筛选容忍度，不能据此宣称统计非劣效；本轮每档36次，一次约2.78个百分点，两个额外失败约5.56个百分点。门槛用于全18图描述值；easy/middle/difficult分层单独报告，不在小样本层内机械套5个百分点后宣布显著优劣。特别说明总体改善是否掩盖difficult层或少数地图的大幅退化。

### 3.3 切换改善与候选区间

在满足上述开发任务容忍度、且安全质量能解释的候选中：

- 相对参考的地图等权短反向频率减少至少20%，作为实用改善参考；使用0.5秒反向窗口、次数/有效任务分钟。
- 同时报告总切换、退出次数、Recovery占比、单次驻留分布和超时，不能将“不退出Recovery”称为有效稳定性改善。
- 参考频率为0时不计算相对下降率，报告绝对差和无法评估相对改善。
- 找出连续至少两个相邻离散档均满足任务筛选与切换改善的候选段；仅说明已采样网格上的候选可接受段，不声称未测连续数值都已证明鲁棒。
- 不同候选段分开保留，不跨越退化档合并。优先考虑较长的连续候选段，代表值取其离散中间档；偶数档的两个中间值优先较窄滞回（X较接近E）。若多个段并列，报告安全/到达/Recovery代价的Pareto权衡，不靠临时调权硬选。
- 若没有满足20%参考的相邻段，或区间/安全证据仍不清楚，如实报告“不支持明确稳定区间”；可按任务表现优先、切换其次、占用/效率辅助提出工程代表值供审阅，但不能伪称已通过上述区间规则。

扫描完成后不自动新增阈值或重复次数，也不反复调整容忍度。结果不明确时允许保留两个候选提交审阅，不能为了必选一个忽视跌倒或UNKNOWN。

### 3.4 原评分仅作辅助

沿用S=40a+30s+20e+10q：a为到达；s为任务窗非足端非碰撞；e=到达时max(0,1−T/20)，非到达为0；q=1/(1+f/257.8)。先逐run变换，再地图内平均、地图等权平均；257.8和权重不重新拟合，缺必要字段则总分UNKNOWN。

评分不是主要资格判据或完整安全指标；跌倒、足端事件等仍独立展示，不因高分越过安全审查。前三轮与本轮分开描述，不拼成一个大样本排名。

## 4. 调度、统计与解释

调度种子2026101801。两轮各108项，每轮18个地图块、每块六档相邻；地图顺序按种子随机。第一轮用随机基础排列的六种循环位移，18个地图块每种位移分配3次；第二轮每图反转第一轮档位顺序，地图块顺序另行随机。全36个地图块中各档在六个顺序位置各出现6次。冻结216项键（地图、重复、X），恢复不重排，不重跑有效项。

保存cycle0实测具名q/dq、姿态/速度和身份；有可控种子则同图同重复共享，无则明确不可控制。重复号不等于初态严格重放。

报告层次：逐地图×六档（108格）→easy 3图/middle 6图/difficult 9图分层→全部18图地图等权。整体17%/33%/50%的地图比例是有目的设计，不暗示真实环境分布。若补充其他层权重，必须显式标成敏感性分析，不能替换主分析。

使用地图成簇、保留同图所有档与重复关系的bootstrap，10000次、种子2026101802。主整体比较可按3/6/9分层重抽地图保持比例；各层同时报告原始计数，easy仅3簇的区间尤其有限。报告与参考的差值区间，而非只用两档各自区间是否重叠判断。未显著不等于等效，点估计过门槛不等于已证实非劣效。

时间：成功到达时间单列，注明两档成功子集不同；另给同图同重复都到达的选择性配对时间差。失败/超时不伪造到达时间。短反向频率与总次数/时长并列，说明提前碰撞会截断事件观察。

可从既有完整帧增加退出后0.5秒内重入Recovery比例，保留退出次数；0次退出为N/A而非0%。覆盖不足为UNKNOWN，终止附近观察不到完整0.5秒的退出需删失标注，不算未重入。碰撞前是否进入/退出Recovery仅按时间关联说明；未触发Recovery的碰撞单列，不能假定由退出阈值解决。
