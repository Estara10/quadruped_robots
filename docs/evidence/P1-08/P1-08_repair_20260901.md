## Repair A — authoritative sim-clock contract (v2)

### A1–A3. Strict odd/even seqlock + versioning + reader validity

`common/abs_sim_clock_contract.h` bumped to **`kVersion = 2`**:

- **Writer** (`SimClockWriter::publish`) now marks `sequence` **ODD** before
  writing any payload field, writes every payload field, then publishes an
  **EVEN** `sequence` only after all payload fields are written, using
  acquire/release atomics (`__atomic_load_n`/`__atomic_store_n` with
  `__ATOMIC_ACQUIRE`/`__ATOMIC_RELEASE`). The previous v1 protocol wrote the
  payload before the even publish, which left a torn-read window (a reader could
  observe an old even sequence while the payload was being overwritten).
- **Reader** (`readSnapshot` / `validSnapshot`) accepts a snapshot only when:
  magic matches, **version matches exactly** (no silent old-version fallback),
  the **before/after sequence is equal, even and non-zero** (odd/in-progress and
  changed-during-copy snapshots are rejected and retried), the monotonic
  timestamp is non-zero, and `sim_time` is **finite** (NaN/±Inf rejected).
- No reader path can accept a cross-field torn snapshot: the two bracketing
  sequence reads (acquire) around the payload copy guarantee consistency.

```
identity = sha256( json.dumps(INPUT, sort_keys=True, separators=(",", ":")).encode("utf-8") )
```

`process_facts.json`; model-closure/binary/plugin/policy/config hashes from the
manifest; git commit + dirty fact; capture dir name; generator version/hash.
