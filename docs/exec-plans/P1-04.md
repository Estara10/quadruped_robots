# P1-04 — Agile 61-D Observation Parity

Status: **ACCEPTED WITH KNOWN ISSUES — independent review 2026-08-31**

## Objective

Prove or precisely classify the relationship between:

- training: `LeggedRobotPos.compute_observations()` (`ABS/training/legged_gym/legged_gym/envs/base/legged_robot_pos.py`)
- deployment: `StateRL` → `AbsObservationContract` → deployed Agile policy input
  (`quadruped_ros2_control_humble/.../FSM/StateRL.cpp` +
  `.../FSM/AbsObservationContract.cpp`)

for every element of the 61-D Agile observation. The P1-01 local parity fixture
proves vector assembly only when upstream values are semantically equivalent;
P1-04 closes the **upstream field semantics**: source, frame, unit, scale,
transform, order and validity behavior.

## Oracle

The real training implementation `LeggedRobotPos.compute_observations()` is the
oracle. It is imported and executed by `scripts/test_p1_01_local_contract.py` —
never recreated manually. The deployment side is exercised through the compiled
`p1_01_abs_observation_adapter` (which calls the SAME production
`abs_observation::agile` used by `StateRL::computeObservation`).

## Test reuse

`scripts/test_p1_01_local_contract.py` (P1-01) is reused unchanged. It feeds an
asymmetric fixture to the real training `compute_observations()` and to the
production adapter, then compares element-wise (Agile61, RA19, Recovery49) plus
semantic helpers (finite, contact temporal filter, rolling timer, ray
validity). A P1-04-specific test is added only if a required semantic boundary
is not covered; the existing test covers asymmetric values, contact
current/prior combinations, timer start/mid/roll, nominal bias, previous-action
ordering, and ray NaN/Inf validity.

## Required semantic boundary cases (coverage)

| Case | Covered by |
|---|---|
| asymmetric values across all legs/joints | test fixture (P1-01) |
| goal values multiple body-frame quadrants / nonzero yaw | source evidence (INTENTIONAL_VARIANT goal shaping) — assembly transform is identity on both sides |
| timer at start / mid / end / reset boundary | adapter semantic helper `timer:[1.0,.5,1.0]` + source (rolling vs linear) |
| current / prior contact combinations | adapter semantic helpers `contact_touch/liftoff/next` |
| nominal joint offset and deployment bias | test fixture (bias=[0]*12) + source (training randomizes ±0.08) |
| previous-action ordering | asymmetric fixture actions |
| normal rays + missing / stale / NaN / Inf | adapter semantic helper `ray_valid:[1,0,0,0]` + `rayFrameValid` |

## Test rules

- `MATCH`: element-wise equal against the real training oracle (tolerance
  1e-5), reproducible by `test_p1_01_local_contract.py`.
- `INTENTIONAL_VARIANT`: names the exact code path and why it is not parity;
  never called MATCH.
- `MISMATCH`: exact indices, values, causal code paths.
- `UNKNOWN`: stays UNKNOWN; no defaults, visual behavior, filenames, or
  operator statements.
- DEC-010 declared policy order (`FL,FR,RL,RR`) is used only as the declared
  operational mapping, never as immutable historical metadata.

## Code-change gate

No production code is altered by default. A fix is allowed only if: (1) an
unexpected MISMATCH is reproduced; (2) exact affected indices + expected
training-oracle values are known; (3) the smallest fix is limited to P1-04
observation construction; (4) regression tests prove it; (5) no
policy/model/threshold/gain/switching/solver/scene/config semantic change. If
any condition fails, report BLOCKED or classify accurately.

## Runtime gate

No MuJoCo / ROS2 runtime run is authorized. If offline/compiled evidence cannot
establish that production `StateRL` uses the tested observation helper, stop and
report the exact missing proof.

## Acceptance conditions

- all 61 elements have a parity-matrix entry with evidence;
- every claimed MATCH is covered by a reproducible element-wise oracle test;
- all differences are explicitly classified;
- no unclassified index shift, joint permutation, default-filled value, or
  silent non-finite value remains;
- existing P1-01 contract regression still passes;
- `git diff --check` passes;
- independent Reviewer disposition is recorded with any remaining known issues.

## Independent Reviewer disposition — 2026-08-31

**ACCEPT WITH KNOWN ISSUES.** The independent Reviewer confirmed all 61 slots
are covered, every `MATCH` claim has real-training-oracle/production-adapter
evidence, and all upstream variants are explicitly classified. It independently
reproduced the local parity test after redirecting the Isaac Gym extension cache
to `/tmp`; the unredirected first attempt failed only because its default cache
was read-only. The Reviewer also confirmed `LeggedRobot.step()` clips
`obs_buf` before returning the training observation, consistent with the
deployment `±100` clamp. Fixture values are in range and the full downstream
policy-library chain was not inspected, so this remains a documented known
issue rather than an out-of-domain equivalence claim. See
[`REVIEW_2026-08-31_PARITY.md`](../evidence/P1-04/REVIEW_2026-08-31_PARITY.md).
