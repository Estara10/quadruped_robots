## Objective

Implement two explicit RA-to-Recovery switching modes, preserve the current
stabilized behavior as default, and prove their boundary behavior with
deterministic offline tests. This task addresses **only switching semantics**;
it does not make the full controller paper-faithful (P1-06 optimizer/Eq.22
mismatches remain recorded, not fixed).

## Mode contract (exactly two valid modes)

| Mode | ENTER Recovery | EXIT Recovery | Forced hold |
|---|---|---|---|
| `paper_faithful_switch` | `RA >= -0.05` (equality enters) | `RA < -0.05` (immediate) | none |
| `stabilized_switch` (default) | `RA > -0.05` (strict) | `RA < -0.08` **and** hold expired | 30 policy steps (`recovery_hold_steps`) |

Config key: `abs.switching_mode` in
`descriptions/unitree/go2_description/config/abs/config.yaml`. Default is
`stabilized_switch`. Any other value is rejected at initialization
(`loadYaml`) with `RCLCPP_FATAL` + `std::invalid_argument`; there is **no
silent fallback**. Non-finite RA can never drive a transition: `runRAModel()`
fail-closed upstream (unchanged), and the helper additionally refuses any
decision on NaN/Inf (`invalid=true`).

## Implementation (smallest change)

- `controllers/rl_quadruped_controller/include/rl_quadruped_controller/FSM/RASwitchingLogic.hpp`
  — **new** pure, dependency-free (no torch/ROS) helper: `SwitchMode`,
  `parseSwitchMode`, `SwitchState`, `stepSwitching()`. Single state-machine
  boundary; all thresholds/hold are caller-supplied.
- `StateRL.cpp` — the inline ENTER/EXIT block in `runModel()` is replaced by a
  call to `stepSwitching()`; `enter_edge` triggers the existing
  `computeRecoveryTwist()` + cache + log (unchanged optimizer). Exit log is
  mode-aware (paper returns at `-0.05`, stabilized at `-0.08`).
- `StateRL.h` — member `switching_mode_ = stabilized_switch` (default).
- `config.yaml` — `switching_mode: "stabilized_switch"` + contract comment.
- `test/p1_07_switching.cpp` — **new** offline deterministic truth-table tests
  (both modes, same RA sequences, all threshold equalities, non-finite RA,
  invalid-config rejection, stabilized regression vs the literal pre-P1-07
  reference logic). Registers in `CMakeLists.txt` `BUILD_TESTING`.
