## model-probe boundary

`p1_08_model_probe.cpp` is an **offline static probe** (loads the scene, prints
`mjModel` facts, steps the model a few times for an arithmetic check). It is
**not** part of the main simulator runtime clock contract and does **not**
promise that its `mj_step` publishes the sim clock. The three runtime `mj_step`
paths (PhysicsLoop ×2 + UI step-forward) remain covered; `publishStep` with no
hook installed is a no-op, not a library-global every-step guarantee.
