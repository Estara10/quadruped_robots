## 当前研究目标

通过已有问题分析，建立符合机器人感知和运动能力的高难度地图，找到合适的退出阈值X和最小保持时间H，使切换约束在困难场景中产生实际任务收益。进入阈值E也可以重新研究，但新配置须与原A/B/C/D分开记录。

接受频繁、短时反向切换是正常现象。主要比较安全完成、碰撞、到达、超时、推进和耗时；切换次数与Recovery占比帮助解释行为，不单独判定方法好坏。

## 当前已接受的新路线

按场景特点研究参数的收益与代价，重点是连续障碍的前后间距、有限绕行空间的通道净宽。每类先拟一个模板和宽/中/窄三档，共6张开发布局；具体尺寸读图后确定，不按A失败或B/C获胜分类。

单障碍不再安排完整选参或通过率扫描，以单阈值为参考，只保留必要的耗时比较。用户对单阈值的观察作为范围取舍，不写成已经证明的普遍最优结论。

下一项是只读整理场景设计表，之后再分阶段执行邻近阈值比较、布局梯度比较、必要的H研究及同类随机新图验证。已讨论的三档E/X为−0.03/−0.06、−0.04/−0.07、−0.06/−0.09，配原A_REF、五图各6次，建议120项，尚未运行。新路线与完成标准见[R1计划](designs/R1/PLAN.md)。本轮只更新规划，不生成地图、不启动批次。
