# M1 地图库规则（m1-mapset/1.0 冻结版）

状态：Director对 M1 给出有条件通过。地图集 `m1-mapset/1.0` 的地图内容、命名、开发/留出划分及运行前确定的规则保持固定；留出集继续不运行策略。此冻结不代表正式实验批准。规则不按运行成绩追改；地图改变须另建版本。

## 研究范围与感知依据

地图服务于 Go2 前向局部避障和 A/B/C/D 切换，不要求策略遵循任何参考路线。当前 MuJoCo 射线生产代码定义11条水平射线，角度从 -45° 至 +45°、间隔9°、范围0.1–6m，起点位于机身 x=-0.05m。该视野说明为什么本版优先短障碍、缓和S和错位路线；它不证明旧地图一定不可通过，也不证明新图策略可达。几何参考线仅用于检查和图片。

## 尺度与几何硬约束

| 项目 | M1候选规则 | 说明 |
|---|---:|---|
| Go2平面保守包络半径 | 0.65m | 沿用 S6-09/S6-11 既有工程包络，未做步态实测 |
| 工程余量 | 0.10m | 不缩小 |
| 参考路线中心至真实障碍边缘的净距 | 至少0.75m | 包络半径加工程余量；连续路径按实际形状检查 |
| 障碍最大投影尺寸 | x方向0.85m，y方向0.75m | 以旋转后的箱体/短条外轮廓或圆柱直径计算 |
| 任意两物体实际轮廓净距 | 至少0.50m | 不等同于必经通道宽；同时检查障碍组合是否形成等效封堵 |
| 起点/目标到障碍轮廓净距 | 至少0.95m | 起点与目标按实际形状距离检查 |
| 场地生成边界 | x=[-0.5,8.0]m，y=[-3,3]m | Director接受的范围候选；只用于生成/记录，没有实体围墙，场外绕行仍可能发生 |
| 起点/目标 | (0,0)m → (7.5,0)m | Director接受；7.5m处于ABS Go1-position训练配置前向目标范围[1.5,7.5]m的上界，不是已验证的策略可达范围 |
| 短障碍纵向节奏 | 主要障碍边缘间距候选至少1.5m | 让局部绕行后有向前恢复空间；样例中S为3.41m，错位为2.30m |
| 几何连通网格 | 0.05m | 搜索参考路径候选 |
| 连续真实轮廓检查 | 沿路径采样0.025m并做旋转形状距离 | 包络路径还需满足0.75m净距；网格仅用于找路，不代替连续检查 |
| 参考方向约束 | x单调向前；缓和S最大方向角≤45°，错位短障碍≤50° | 角度相对目标前进方向；不允许必须后退才能找到路 |

不允许用紧密并排短块伪装成长墙。除单物体尺寸外，还要检查所有实际轮廓、相邻物体净距、连续路径和替代通路；不得把最近物体间距或参考路线“中心线包络宽度”冒充实际两侧障碍开口。缓和S仅称“可行参考路线”，供几何检查和图片展示，不送入策略；策略允许更直接的局部绕行，不为强迫走S形增加封堵。全库生成需改变主要障碍的位置、尺寸、朝向和错列方式，不能只通过外围填充障碍制造密度差别。留出集使用独立种子并在策略运行前固定划分，不按策略表现筛选或修改。密度是几何标签，不等于风险或难度。

旧 S6-09 的占地比例带不直接继承：扩大的空旷场地和短障碍结构需要重新分档。阶段1提出以下互不重叠区间，分母为声明场地区域面积，分子为实际障碍XY投影面积之和。占地比例只表示几何占地，不等于难度；每图同时记录物体数、各障碍尺寸、最小实际物体净距、主障碍纵向间隔、路线长度、绕行比、路线最小障碍净距和最大方向角。

|---|---:|
| 稀疏 | [0.8%, 1.9%) |
| 中等 | [1.9%, 3.2%) |

四个阶段2样例的占地比例分别为0.846%、2.078%、1.610%、2.103%，落在对应区间。不为达到比例而塞障碍或压缩通道；密度不作为风险、难度或策略性能标签。

## 目标、计时和越界候选口径

只读代码核对发现：Go1 position训练配置 `go1_pos_config.py` 的 `commands.ranges.pos_1` 为1.5–7.5m，episode长度9s；当前控制器从YAML读取world-frame目标，将到目标向量按 `min(1,5/(distance+0.01))` 缩放，且将9s episode timer归一化输入策略。当前采样到的控制器代码中该timer被重置、递增并用于归一化，未找到它作为运动硬终止条件的分支；这不证明超出训练范围可用。图审接受7.5m目标，不扩展到9–12m。

`s1_run_diagnostic.py` 有 `--goal-x`、仿真上限和墙钟上限；`manual_ab_compare.py` 的旧入口把7m目标写死，须改为逐图配置。阶段3逐图目标、场地、时限须由配置、运行器、controller消费检查、recorder、终局记录和analyzer一致传递，不能只改XML。批次冻结条件：起点(0,0)、目标(7.5,0)，到达半径0.5m；运动仿真上限20s、墙钟120s；到达后站立观察5仿真秒、站立墙钟上限30s。该时限依据已审图的7.5m目标与最长约9.7m参考路线，沿用已有诊断监督上限，是统一监督边界，不代表策略episode timer。策略9s timer作为观测输入，保持不变。四组A/B/C/D条件沿用已有合同，每图相同目标和时限。

越界规则（运行前冻结）：从RL首周期起按每个具名策略帧保存base XY、session/cycle、时钟有效性及目标/场景身份。以x=[-0.5,8.0]m、y=[-3,3]m为声明范围，任一坐标超出范围即记录越界。只按相邻、连续且仿真时钟有效的样本计算越界时长；缺帧、无效或不连续区间不插值，持续时间记UNKNOWN/不完整。边界不是墙，越界不覆盖supervisor原始终局；若轨迹/终止状态显示越界，运行仍保留为诊断，但不计作“声明范围内有效到达”，另表列越界完成。覆盖不足时越界状态UNKNOWN，不能算未越界。运行开始后不因结果改变该口径。

12条历史S6-11 A运行均消费7m目标，目标、场地/任务语义改变后的新图或7.5m运行不使用这些记录补足重复次数。全库和实际运行版本在首个场景运行前记录：地图版本、生成器版本、seed及dev/held-out清单版本、实际C++ MuJoCo运行端指纹和M1运行器/分析器版本；阶段5不得按成绩追改。

## 后续阶段额度与停止规则（候选，图审后细化）

- 开发图上固定 A、E=-0.05；全库目标30张开发图，每图最多3次，共90条场景run额度。旧12次S6-11 A运行只有在地图几何、目标、模型、控制链和终局规则逐图兼容后才能计入；修改几何后的历史运行不计入。
- 留出图不运行策略、不用于参数选择或按成绩删图。
- 合法碰撞、跌倒、超时和安全终止保留为有效任务结果，不重跑追求到达。基础设施故障需先停批、留原始数据、定向修复和离线核验；重试仍受 M1 阶段4额度限制。
- 不改变模型、观测、切换参数、控制算法、运动安全或停止规则。策略失败不自动判地图无效。
- 每次运行后先关闭MuJoCo，再关闭本次controller/ROS/采集和辅助进程，并按 AGENTS.md核对退出。

阶段1/2为待用户图审的方案和原型，不冻结全库、运行额度细节或最终实验条件。
