# M3 v1.2：02、04、06的前向开口修订

用户观察到原布局容易向侧方钻入，图示参考路线与实际运动相差较大。本次只调整02、04、06的障碍位置，保持形状、尺寸、数量及控制设置。

## 具体改变

- 起点正前方设置2.5m可进入段，中心线对障碍净距至少0.75m；此值按原0.65m包络与0.10m余量计算。
- 首组障碍移至左右两侧，名义起点中心附近可看到开口；后段仍保留局部绕障，不铺设长墙。
- 名义起点x=-0.05m、朝向+X的11束几何射线中，−9°、0°、+9°三束均至少3m无物体命中。射线是点射线，机器人通行还需同时满足包络净距。
- 后续参考路线重新计算，先经过(2.5,0)，再绕过后段障碍；参考线只证明几何通路，不作为机器人导航输入。

## 范围与限制

不能从现有目视反馈唯一认定旧图是右侧射线缺失或传感器错误。本轮只改善地图的初始通行条件，没有改变感知范围或加入路径规划器；策略仍可能选择别的方向或失败。
这是名义起点静态几何核对，不是实际运行传感或策略验证。02、04、06已改变几何，原源图历史失败比例仅说明选入原因，不代表本版本的失败率。
M3版本更新为s7-challenge-test/1.2；其余27张XML不变。v1.1资料及三张旧XML保存在history/v1_1_before_initial_opening/。
