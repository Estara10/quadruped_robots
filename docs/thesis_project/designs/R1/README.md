## 研究目标

通过已有问题分析，建立符合机器人感知和运动能力的高难度地图，找到合适的退出阈值X和最小保持时间H，使切换约束产生实际任务收益。进入阈值E可重新讨论，候选设置须与原实验分开记录。

频繁、反向切换是正常现象。主要看安全完成、碰撞、到达、超时、推进与耗时，切换次数仅用于解释。
