# 当前射线预测模型：已有动态结果复核

更新：2026-11-03。范围仅为原12项批次已有日志；无新增仿真、模型推理或参数调整。

## 结论与建议

**主建议：3. 暂缓当前预测模型的进一步动态投入。** 暂不把它作为challenge27导航射线的可用替代源继续扩展动态试验。最关键的补充应是同位姿、同朝向的预测射线与既有几何射线配对记录，尤其在障碍02接近区，并让每帧预测输出、控制器消费和物理接触有可核对的时间/位姿关联。已有记录还不足以确定两次碰撞由模型误差造成，也不足以说明模型普遍无效。

静态比较和这批CUDA动态记录没有证实输入单位、束序或明显错误转换；CUDA链路在计划项4、6、7、9、10正常运行且读取未超过200ms保护。但在challenge27的两次预测运行都碰撞障碍02；同批challenge27几何为2次到达、1次20秒限时。scene_flat预测则2次到达、1次限时，几何3次到达。开阔场景预测限时项末端距目标0.718m，另两次预测到达约0.486/0.480m。这个组合值得先核对动态输入与控制使用关系，再决定继续投入。

## challenge27 两次碰撞：已知与未知

两次均为有效任务期碰撞，事件记录都指向`ppt_obstacle_02`，机器人接触主体记录为`base_link`（robot geom id 14未命名）。计划项7在仿真时刻约16.106–16.138s接触，末端距目标3.475m；计划项9约17.956–17.978s接触，末端距目标3.514m。两次起始目标距离都约7.539m。路线结果因此相似：都向目标推进约4.0m后与同一登记障碍发生接触。现有证据支持“相近场景区域/障碍处失败”的描述，但不能证明轨迹、朝向和具体避障动作相同。

控制器射线约定已在原静态比较核对：11束对应−45°到+45°、每9°一束；共享帧payload为`log2(米)`，预测器输出转换回米后写入与控制器相同协议。原静态同位姿比较没有发现束反序迹象，challenge27四个静态姿态的MAE/RMSE/最大误差为1.355/2.067/4.963m，false-safe为0/44，false-danger为19/44。静态误差整体偏短，不等于碰撞前动态射线也偏短。

目前不能根据保存材料作可信的碰撞点同位姿几何减预测差值：物理接触有精确仿真时间，但射线读数日志以策略周期/帧记录，现成导出没有把碰撞物理步、该周期的机体位姿/朝向、障碍02方位、对应预测帧及同位姿几何参考组成经验证的同步样本。因而“模型在障碍方向明显高估/漏判”**没有直接证据**；也不能据此排除这种情况。任务期预测更新有记录，未见第7、9项发生200ms保护中止，但这只能排除已记录的明显过期事件，不能证明图像到控制使用的总延迟或预测值正确。碰撞前Agile/Recovery、RA、射线和动作即使有短时相关，也不足以建立原因。

同图几何运行并非单一结果：第1、11项到达，第5项限时且终距4.191m；因此challenge27本身难度和初态/策略路径会影响表现。几何2/3到达、预测0/2到达且2/2碰撞是本批观察，不是统计上可推广的模型劣势结论。

## scene_flat CUDA预测限时项（第6项）

第6项从目标距离约7.539m推进至0.718m，接近0.5m到达半径但在20仿真秒限时结束。它有约35.3%的有效运动时长处于Recovery；预测到达项第4、10项分别约22.8%、17.5%。这构成“限时项Recovery占比偏高”的单项线索，但预测到达也有明显Recovery，并均到达；几何三项未进入Recovery且到达。因此不能说Recovery占比本身解释超时，更不能把预测的较短距离直接称为错误。

scene_flat注册为无障碍开阔场景，未声明有限围栏；它并不等于所有射线方向都必须输出量程上限，机器人本体、地面/模型可见结构及相机视角仍影响预测。当前报告没有针对第6项末段每个短射线束的可见几何真值。没有证据证明最后约3秒持续“假近障”或射线停更；更稳妥的观察是它已经接近目标但在限时前未跨过到达半径，恢复/动作推进关系仍需谨慎解释。实际速度、目标航向与动作跨时间响应，现有归档没有可审计的同步案例表，本报告不推断其为停走、绕行或往返。

## 决策边界

事实：两次challenge27 CUDA预测均与障碍02接触；scene_flat预测三项中两次到达、一次接近目标限时；没有证据显示这三项触发预测时龄保护。静态模型对比未见false-safe，但存在明显距离误差和false-danger。

解释线索：障碍02附近的动态预测/动作配合可能不足；开阔场景限时项Recovery占比高且终距接近到达阈值。

无法判断：碰撞方向束是否高估或漏判、碰撞前真实相机视野中的障碍方位、预测更新与控制消费完整时延、scene_flat末段近射线是否对应可见物体、Recovery是否导致推进不足、两次碰撞是否走同一条精确轨迹。

所以建议暂缓用当前模型扩展动态实验，优先利用已有日志做一次有界的同周期数据核对（若现有字段可直接支持），并在后续获准的有限验证中把预测射线与同位姿几何参考配对；不建议现在改模型或安全阈值。小样本不能证明模型普遍优越或普遍无效。独立CUDA诊断的起点UNKNOWN和收尾DDS超时按既有状态保留，不在本报告追查。
