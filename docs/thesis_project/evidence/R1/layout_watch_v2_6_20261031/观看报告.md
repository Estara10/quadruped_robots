# R1 v2六图A组观看记录

日期：2026-10-31。用途：观察v2布局是否改变实际走法，不估计通过率、不比较策略组优劣。

## 接入与运行条件

六张地图以`r1v2_*`独立身份登记，R1 v2清单位于[layouts.json](../../../designs/R1/generated_maps_v2/layouts.json)。现有C++身份探针实际加载六张XML，取得真实模型指纹，核对障碍数为d09每图10个、m02每图9个；登记和清单同步后增量构建成功。诊断器清单核对也通过。

运行入口为`/usr/bin/python3 -u scripts/manual_ab_compare.py`，每次`--groups A --repeats 1`，窗口可见、`--no-rviz --disable-framebuffer-capture`。统一目标(7.5,0)、到达半径0.5m、20仿真秒/120墙钟秒、到达后站立观察2仿真秒。运行上下文确认A组有效E=X=−0.05、滞回关闭、H=0；CLI兼容参数X=-0.06未由A组消费。六张有效记录均VALID。

首次v2宽档尝试在进入策略前被物理权威检查拒绝；检查记录显示目录与清单的模型指纹仍为全零占位，实际运行指纹为`da9abc…`。已用现有C++探针重取六个指纹、同步场景目录与清单并增量构建。失败原始记录保留在批次目录；补做的首图未产生导航周期，之后取得唯一有效导航结果。六次有效导航均未重跑。

## 轨迹与判断

[六图实际轨迹对照图](../../../../../logs/09_R1_switch_constraints/r1_v2_layout_watch_20261031/six_map_actual_paths.png)使用已有位姿帧，仅绘制`rl_active`且不晚于终局策略周期的样本，因此不含终局后站立或收尾轨迹。红色为本轮移动障碍。未保存录像或自动截图。

- d09三档均实际经过研究区域，方向变化表现为绕01上侧后向02下侧转回。宽/中两条路线相似；窄档在02碰撞。单次结果说明新布局被实际遇到，并显示一条合法碰撞，不足以证明间距变化造成稳定的路线或任务效果。**建议保留三档作为后续比较候选**；窄档碰撞不作为删图理由。
- m02三档均选择03—07间隙，没有走03上方。宽/中档在03碰撞，窄档到达。被改动区域确实进入实际路线，适合继续研究；但宽/中碰撞且窄档到达并非单调结果。**建议三档先保留，宽/中列为布局审阅重点**，由人工决定是否调整03附近空间；单次样本不足以据此自动改图。
- 每图仅一次初态，不能估计通过率、比较策略优劣或宣称三档风险单调。碰撞图展示的是有效负面结果，未补跑。
