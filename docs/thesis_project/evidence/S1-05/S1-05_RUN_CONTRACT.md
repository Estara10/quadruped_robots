## 安全事件定义

- 仿真碰撞权威源在 MuJoCo PhysicsLoop 每次 mj_step 后读取接触。robot geoms 由当前模型 group 3 识别；障碍物由现有七个几何签名绑定。只有 robot-obstacle 接触计入“障碍碰撞”。
- 与名为 floor 的地面接触单独分类。只有机器人几何与地面接触进入 ground 计数；几何名为 FL/FR/RL/RR 的脚掌地面接触记为正常脚掌接地，其他机器人几何与地面接触计为非足部地面接触。静态障碍物与地面接触归入 other，避免混入机器人地面计数。自碰撞、其他已识别接触和无法分类接触分开保留；不把它们改写为障碍碰撞或无碰撞。
- 障碍接触从无到有开始一个 episode；接触跨连续 PhysicsLoop 步时继续同一 episode，接触消失后再次开始才记新 episode。持续时间累加连续接触步之间的仿真时间。最多保存 32 个 episode；溢出时不作完整无碰撞判断。对象 ID 始终保存；模型对象无具名名称时名称为空且不猜测。
- 碰撞、未分类接触、无效姿态及跌倒事件累计器均在本次 MuJoCo authority 初始化时归零。发布器记录首末物理步和仿真时刻；物理步号或 sim_time 间隔不连续会永久标记本次覆盖不完整。UI 单步不属于发布器覆盖。未分类接触按物理步累计，并保留首末发生范围；发生范围与运动区间重叠时，障碍碰撞结论为 UNKNOWN。多个相隔事件形成的首末范围可能保守覆盖中间无事件时段，因此只会扩大 UNKNOWN，不会据此判为无碰撞。
- 跌倒候选按 episode 保存于 32 项环形历史中，包含起止、确认时刻和闭合标记；正常观测关闭当前 episode 并允许后续跌倒建立新 episode。环形历史溢出、发布缺口或旧版快照缺少事件锁存字段时，不允许输出否定结论。完整碰撞否定结论还要求有效 authority、物理覆盖连续、无相关未分类接触和历史溢出，并覆盖运动起点至终止周期。

## 跌倒候选规则

- 位姿取 MuJoCo 世界坐标中的 base_link：xpos.z 为米，xquat（w,x,y,z）换算 roll/pitch 为弧度。
- 本次诊断的候选条件为：机身高度 <0.22 m，或 |roll|>60°，或 |pitch|>60°；任意一项持续满足 >=0.30 有效仿真秒后确认。严格姿态边界相等不算候选，持续时间边界相等可确认。
- 每个候选 episode 首次出现时记起点，持续异常期间只更新同一 episode，不按物理步重复计数。满足持续时长后记录确认时刻；有效正常姿态关闭 episode 并重新武装，因此启动期确认后恢复，再在运动期跌倒会得到新的独立确认事件。
- 无效姿态和物理步/仿真时间覆盖缺口按物理步累计并保留首末发生范围。它们不会被解释为恢复；未确认候选跨越运动起点时，运动期跌倒结论为 UNKNOWN。已确认 episode 与运动区间有重叠时报告运动期跌倒，包括确认发生在运动开始前但异常持续进入运动区间的情形。启动期 episode 若已在运动起点前恢复则不计入运动期。范围发生重叠、历史溢出或发布覆盖不完整时不允许报告“未跌倒”。首末范围跨过运动区间但中间可能没有异常时采取保守 UNKNOWN。
- 无效姿态会打断未确认候选的有效持续时间；下一个有效异常样本从该时刻重新计时，但保留同一未闭合 episode。已确认 episode 不因一个无效姿态样本而重复确认或关闭。阈值仅为本次诊断规则，正式阈值留待 S6。
- 规则在每个物理步评估，候选 episode 历史可保留两次策略采样之间开始并结束的确认事件；物理发布器缺失、步序不连续或 32 项历史溢出时，相关否定结论为 UNKNOWN。接触/姿态条件如果持续不足一个物理步，仍不保证被 MuJoCo 离散采样观察。
