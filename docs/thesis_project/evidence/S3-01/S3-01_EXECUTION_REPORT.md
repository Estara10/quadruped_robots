# S3-01 执行报告：B 组双阈值滞回与 A/B 单次功能诊断

**状态：COMPLETE（2026-10-11，Director 有条件通过）。** 本报告记录生产实现、针对性离线核验和随机场景04各一次有效 A/B 诊断。两次都是非正式单次功能观察，不构成正式实验或性能估计。通过范围限于 B 机制、配置及功能验证，以下限制继续保留；后续配置隔离流程核验由 S4-01 承担。文末 ACTIVE/等待审阅属于提交时的历史状态。

## 做了什么

- 新增生产配置解析和切换模式 B。A 保持单阈值语义；B 的进入条件为 `RA >= E`，Recovery 仅在 `RA < X` 时退出，`RA == X` 保持 Recovery。B 无保持时间。
- 配置解析拒绝缺失/非法阈值、未知组、旧字段冲突及不允许字段；C/D 仍明确不支持。运行来源日志与记录包含 group、实际 E/X、滞回和保持标志。
- 新增实时帧的 B 模式标识，并同步 reader、记录器和来源匹配器。未改变 RA 模型、三模型输入/输出、观测排列、动作映射、限幅、Recovery 控制路径、频率、场景安全规则或 A 的切换规则。
- 实际运行时 A 使用 `group=A, E=-0.05, X_effective=-0.05, hysteresis=false, hold=false`；B 使用 `group=B, E=-0.05, X=-0.08, hysteresis=true, hold=false`。两组的来源匹配器均确认 controller、session、唯一 writer、配置、模型和目标来源一致。

- B 有 10 个全采集无效时钟帧、7 个运动期无效帧。模式边界仍计数；需要仿真时间的驻留及路径指标仅覆盖有效部分。
