### 审阅保留限制

- A/B 缺少关节初态样本；C/D 具名关节样本与 RL 起点不同步。
- B/D 正常站立观察未完成，均使用 command 9 回退；controller PASSIVE 确认不代表 MuJoCo 消费确认。
- 碰撞否定覆盖不足，部分跌倒结论为 UNKNOWN；D 的两个保持 episode 不完整，整体保持审计仍为 incomplete。
- 首批 C 的原始 INVALID、D 原始 cleanup 状态错误及纠正说明均保留；旧安全测试 fixture 不匹配的失败也保留，不能概括为全部相关检查通过。
- 四组数据来自不同批次，不能据此比较成功率或性能优劣。
