## 解释规则

- “完整覆盖”是运动窗口边界快照和 PhysicsLoop 发布累计证据共同支持的该窗口判断。不能用全采集区间字段替代运动区间判断，也不能把运动窗口结论外推到启动/收尾阶段。
- 策略周期稀疏采样不等于物理步遗漏；完整性来自发布器连续性和累计历史，而不是要求每个物理步都对应策略帧。
- 无效时钟不删除离散模式边沿，但相关持续时间、驻留和路径指标只能在有效连续片段计算。
- 每组只有一次诊断，初态采样时刻也不同；不据此形成算法优劣或参数结论。
