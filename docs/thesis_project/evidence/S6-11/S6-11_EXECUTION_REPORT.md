## 调整依据与量化规则

当前 Go2 ray producer 定义11条水平射线，角度从−45°到+45°、间隔9°，量程0.1–6 m，机身局部起点 x 偏移−0.05 m（`unitree_mujoco/simulate/src/unitree_sdk2_bridge.h` 的常量与射线代码）。这是前向90°观测扇区，不代表旧图绝对不可通过；本次替换基于研究任务范围和障碍布局结构，不是根据策略成功/失败筛图，也没有证明新图策略可达。

Go2保守平面包络半径0.65 m加工程余量0.10 m，中心线到实际旋转箱体/圆柱表面至少0.75 m；这一既有余量没有缩小。规则、尺寸范围、密度、入口/出口定义、有限重采样上限和适用限制详见[地图规则](../../designs/S6-11/MAP_RULES.md)。要点为：

| 项目 | 本轮规则 |
|---|---|
| 场地与端点 | 障碍边界 x=[−0.5,7.5] m、y=[−3,3] m；起点(0,0)、目标(7,0)；障碍至两端边缘净空至少0.95 m。边界不是实体墙。 |
| 单障碍局部尺度 | 按实际旋转轮廓投影，x向不超过0.85 m、y向不超过0.75 m；箱体、圆柱和短旋转条高度沿用0.32–0.62 m。 |
| 障碍间距 | 稀疏至少0.28 m、中等至少0.16 m、密集至少0.10 m，按实际形状间距检查。 |
| 可行路线 | 在现有路径搜索范围内从起点向+x到目标，不能后退；侧偏不超过1.55 m，简化参考线单段方向变化不超过50°；每条线段均对真实障碍轮廓检查0.75 m净距。 |
| 检查分辨率 | 0.05 m网格搜索；最终线段与真实障碍形状以不超过0.025 m的路径检查间距复核。最多96次布局重采样、每次最多2400次填充尝试。 |
| 密度 | 沿用不重叠的投影占地比例：稀疏[6%,9%)、中等[9.5%,12%)、密集[13%,20%)。占地不是难度，另记录障碍数量、实际间距、最小路径净距、路径长度和绕行比。 |

没有为凑密度缩小通行净距。短障碍局部绕行的主障碍直接阻挡中心线；前向错列类以交替侧向短障碍在保守Go2包络层面形成多次小幅侧移，点中心线不一定与障碍实体相交，因此不把这类地图误记为直线阻挡。代表图上的淡色带是机器人包络加余量的几何展示。

## 剩余36张静态审查

对单侧绕行、连续交替绕行和错位通道口的36张保留图，用同一0.85 m局部障碍投影上限、±1.55 m参考侧偏和50°方向规则检查了实际障碍投影与保存参考路径。详表列出每个旧ID、各向投影、超限构件数、路径侧偏、最大线段角、后退长度及直线阻挡。

36张均至少有一个障碍超过新版短障碍投影上限，需要 Director 关注其是否继续适合作为新版主候选：

- 单侧绕行12张的最大路径段方向角约28.3°，但长横向结构投影约3.425 m。
- 连续交替绕行12张的最大段角约81–82°，并含3.325–3.495 m长横向投影。
- 错位通道口12张的最大段角约73.5–80°，并含约3.375–3.445 m长横向投影。
- 这些保存路径均向前且最大侧偏不超过1.55 m；这不抵消长结构与局部短障碍规则的差异，也不证明射线无遮挡或策略可通过。

本轮不改这36张、不按策略表现决定保留与否；交由 Director 审阅是否需要另行授权修订。
