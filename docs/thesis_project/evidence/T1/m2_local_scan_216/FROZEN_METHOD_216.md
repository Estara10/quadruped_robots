**冻结时间：2026-10-18，运行开始前。** 本文件是[216项执行提示词](../../../T1_M2_LOCAL_SCAN_216_EXECUTOR_PROMPT.md)要求的运行前固定评价规则。运行开始后不因结果修改门槛、候选段规则或代表值规则。

## 2. 调度

- 两轮各108项。每轮18个地图块，每块六档相邻。
- 第一轮：随机基础排列的六种循环位移；18个地图块每种位移分配3次；地图块顺序按种子随机。
- 第二轮：每图反转第一轮的档位顺序；地图块顺序另行随机。
- 全36个地图块中，每档在六个顺序位置各出现6次；每档总运行36次。
- 冻结键为（地图、重复、X）。恢复时不重排、不重跑有效项。

## 3. 任务与安全解释

1. 质量与安全先行：任何任务期确认跌倒的档位不进入自动代表值推荐，单独报告原因和不确定性。不把单次事件当真实风险概率。
2. UNKNOWN不补成False。对到达/碰撞分别给出有利与不利情景；若两种情景改变候选资格，标为“证据不足”，不算通过。
3. 超时、墙钟保护、INVALID、UNKNOWN独立展示；不被综合分抵消。
4. 开发性任务容忍度（本轮新运行 X=−0.07 为参考，地图等权）：
   - 到达比例相对参考下降 ≤5个百分点；
   - 非足端障碍碰撞比例相对参考上升 ≤5个百分点。
   - 两个5个百分点是工程筛选容忍度，不是统计非劣效证明。每档36次，约1次=2.78个百分点、2次=5.56个百分点。门槛用于全18图；easy/middle/difficult分层单独报告，不机械套门槛宣布层内显著优劣。
5. 特别检查总体改善是否掩盖 difficult 层或少数地图的大幅退化；逐图差值表与分层表必须同时给出。

## 4. 切换改善与候选段

在满足任务容忍度且安全可解释的候选中：

- 相对参考的地图等权短反向频率减少至少20%为实用改善参考。短反向窗口0.5秒，分母为有效任务分钟。
- 同时报告总切换、Recovery退出次数、Recovery占比、单次驻留分布、超时。不能把“不退出Recovery”称为有效稳定性改善。
- 参考频率为0时不计算相对下降率；报告绝对差并标“无法评估相对改善”。
- 候选段必须是连续至少两个相邻离散档，且每档均满足任务筛选与切换改善。
- 不同候选段分开保留，不跨越退化档合并。优先较长连续段；代表值取离散中间档；偶数档取两个中间值，优先较窄滞回（X更接近E，即数值更大）。多个段并列时给出安全/到达/Recovery代价的Pareto权衡，不临时调权。
- 若无满足20%的相邻段或证据不清，报告“不支持明确稳定区间”；可按任务表现优先、切换其次、占用/效率辅助提出工程代表值供审阅，但必须明确未通过上述区间规则。
- 不因结果新增阈值、重复次数或调整容忍度。结果不明确时允许保留最多两个候选。

## 5. 辅助评分

`S = 40a + 30s + 20e + 10q`：

- `a` = 到达为1，否则0；
- `s` = 任务窗无非足端障碍碰撞且无确认跌倒为1，否则0；任一为UNKNOWN则总分UNKNOWN；
- `e` = 到达时 `max(0, 1 − T/20)`，非到达为0；
- `q` = `1/(1 + f/257.8)`，f为短反向次数/有效任务分钟；
- 先逐run变换，再地图内平均、18图等权平均；257.8和权重不重新拟合。

评分只作辅助，不作资格判据；跌倒、足端事件、UNKNOWN独立展示。

## 6. 统计与不确定性

- 报告层次：逐地图×六档（108格）→ easy 3图 / middle 6图 / difficult 9图 → 全部18图地图等权。
- 主分析使用地图成簇、保留同图所有档与重复关系的分层bootstrap：easy重抽3、middle重抽6、difficult重抽9；10000次，种子2026101802。各层同时报告原始计数；easy仅3簇，区间尤其有限。
- 报告与参考X=−0.07的差值区间（同一次重抽中两档使用同一地图集合），不只比较两档各自区间是否重叠。
- “未显著”不等于等效；点估计过门槛不等于已证实非劣效。
- 成功到达时间单列，注明两档成功子集不同；另给同图同重复都到达的选择性配对时间差。失败/超时不伪造到达时间。
- 短反向频率与总次数/时长并列；提前碰撞会截断事件观察。
- 退出后0.5秒内重入Recovery比例：保留退出次数；0次退出为N/A不是0%；覆盖不足为UNKNOWN；终止附近不足0.5秒观察的退出标为删失，不算未重入。
- 碰撞前是否进入/退出Recovery只按时间关联说明；未触发Recovery的碰撞单列，不假定由退出阈值解决。

## 7. 失败、补做与存储

- 基础216次实际场景；最多4次已定位并修复的基础设施补做；总实际场景最多220；同项最多2次。
- 合法碰撞、跌倒、仿真/任务墙钟终局保留，清理后继续；不重跑合法失败。
- 真实安全veto、来源/记录冲突、清理无法确认先停止定位；仅允许不改变研究/安全语义的最小修正及定向核验后按额度补做。
- 纯前置编排失败明确未创建场景时单独记账，最多2次有界修正，同错复发停；UNKNOWN启动保守占额度。动态台账，不写死attempt总数。
- 数据目录 `logs/t1/m2_local_scan_216/<batch_id>/`；证据 `docs/thesis_project/evidence/T1/m2_local_scan_216/`；预算4 GiB，剩余磁盘至少15 GiB；不删旧数据，不录视频/截图。
- 每次及最终清理本次 MuJoCo、ROS/controller、采集器和辅助进程；核对退出后再继续，不影响无关会话。

## 8. 初始状态与不可控项

保存 cycle 0 实测具名 q/dq、姿态/速度和身份。若现有入口支持可控种子则同图同重复共享；不支持则明确记录“不可控制”。重复号不等于初态严格重放。

## 9. 解释边界

- 18图依据历史表现有目的选择，困难图占比高；easy/middle/difficult为17%/33%/50%，不暗示真实环境分布，也不代表总体成功率。
- 地图不因结果重新分层；困难标签是选图意图，不是测出的风险概率。
- 本批是开发集局部扫描，不是正式A/B/C/D验证，不使用留出集。
- 结束时只提出候选可接受段和代表值建议，待Director审阅；不自动新增扫描、保持时间实验或正式对照。
