# T1 两档退出阈值、36 张开发地图：冻结矩阵与分析方法

批次类别：开发集参数预实验；不是正式实验、A/B 对照或论文性能结论。

## 固定矩阵

- M1 `dev01.xml`–`dev30.xml`（30 张）及 M2 `m2dev01.xml`–`m2dev06.xml`（6 张），共 36 张开发图。任何 holdout 均不入计划。
- 全部 B 组，`E=-0.05`，两档 `X=-0.07` 与 `X=-0.12`，无保持时间；每图每档 2 次，共 144 项，每档 72 项。
- 目标 `(7.5, 0)`、到达半径 `0.5 m`、运动上限 `20 sim s / 120 wall s`；到达后站立观察 `5 sim s / 30 wall s`，观察尾段不计入运动指标。
- 模型、地图、初态准备流程、观测、动作、频率、公共启动增益交接及安全/终局规则保持同一生产链，不根据结果修改。

## 调度

冻结调度种子 `2026101604` 只用于计划顺序，不是仿真随机种子。两个轮次各先随机排列 36 张地图块；每块的两档相邻。第一轮恰有 18 张先跑 `X=-0.07`、18 张先跑 `X=-0.12`；第二轮逐图反转该图的首轮阈值顺序。恢复时读取已冻结计划，不重新洗牌。`manual_ab_compare.py` 与 `s1_run_diagnostic.py` 没有可用的模拟器/策略随机种子入口，故不能使同图同重复的两档共享随机种子；记录的重复号仅表示计划配对，初态可能不同。

## 运行、记录与停止

每项使用独立 B overlay 副本，生产解析器必须接受实际组别、阈值及目标；hold 字段缺省。每项运行保存原始策略周期、物理/安全数据、上下文、终局、分析和进程事实。要求来源、实际消费、cycle 0 初态、终止帧、记录有效性、PASSIVE/站立收尾及进程退出证据均可追查。合法碰撞、跌倒、超时及安全终局保留，不重跑。未确认唯一来源、记录无效、未确认清理、发生安全 veto 或重复基础故障时停止。

基础计划 144 次场景启动；只有已定位并修复的基础设施失败可补做，最多 4 次额外启动、同一计划项最多 2 次。未创建场景的编排失败单独记录；不确定是否启动则占用额度。批次数据预算 `4 GiB`，可用空间下限 `15 GiB`。每 8 项核对存储。预先选定首轮前 4 个地图块的 8 次运行截图；不录视频。

## 指标与比较

- 完整经过时间与有效连续时间分列。路径/速度仅基于有效连续片段；时钟无效、缺周期、覆盖断裂及未闭合段不插值。
- 模式边沿计数保留全部已记录边沿；无效仿真时间边沿不用于精确驻留时间。
- 短反向频率按完整覆盖的短反向计数除以有效任务分钟；覆盖不全时 UNKNOWN。
- 碰撞、跌倒、足端接触/撞击、Recovery 占比、站立收尾、时钟/周期覆盖、安全 UNKNOWN 单独报告。未知不补成零或 False；有效记录不等于安全成功；命令发布不等于 MuJoCo 消费。
- 按接受的辅助分数先逐 run 计算：ARRIVED 40 分；任务窗无终止性碰撞 30 分；ARRIVED 时效率 `max(0,1-time/20)` 占 20 分；完整短反向覆盖的稳定项 `10/(1+f/257.8)`。必需字段缺失则该 run 分数 UNKNOWN，不重分配权重。
- 逐 run 非线性分数先算，再同图同阈值平均两次。只有两次分数均完整的地图×阈值单元才报告完整单元均分；缺一项仅报告可用记录，不冒充完整单元。主差值为 `X=-0.12 减 X=-0.07`。
- 同图同重复的“两档均 ARRIVED”时间子集单独报告并注明选择性；不能只比较各自 ARRIVED 样本后推断因果。
- 分 M1 30 图、M2 6 图、全 36 图汇总。全库地图等权，并保持 30/6 固定构成；不将 M1 与 M2 各 50% 加权。若报告区间，按地图簇配对 bootstrap，10,000 次、种子 `2026101605`，全库抽样按 M1/M2 分层保持 30/6；M2 仅 6 个簇，区间不稳。
- 分数差正/负/相同的地图数和幅度仅作描述；不宣布某档最优，不用每图 2 次推成功率。结果只支持两档 B 开发参数的描述性权衡，不说明相对 A 的效果。
