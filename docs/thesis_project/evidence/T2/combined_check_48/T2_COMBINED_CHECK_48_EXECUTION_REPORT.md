## 指标口径和限制

- 任务时间边界含真实起点和终止周期；任务计时、有效连续时间、路径与速度使用声明运动窗口，不含站立与清理尾段。全48项任务窗口覆盖率1.0，任务周期缺口/策略时钟无效为0。仿真时限本身是任务终局，不等同墙钟超时；本批没有墙钟保护终局。
- 模式边沿按周期变化计数，不因时间戳而删边沿；本批所有边沿时间均有效。短反向定义沿合同的0.5秒窗口；频率只在覆盖完整的run上报告。本批各组12/12覆盖完整。逐run数量保留，汇总以每图等权，避免重复项数较长的图占更大权重。
- 本批全运行任务跌倒指标为false，且分析器报告运动区间跌倒历史覆盖完整、无确认事件；这仅表示当前跌倒规则在本次有限运动窗口未确认跌倒，不是普遍无跌倒保证。没有非足端接触的run也仅在本批完整碰撞覆盖窗口内解释。
- 退出后0.5秒重入分母仅包含可观察完整窗口，删失/未知分开保留；详见逐run字段。接触事件与模式切换时间相邻不构成因果证据。
- 命令写出与MuJoCo消费分开；本批MuJoCo具体命令消费仍UNKNOWN。运行期场地越界只依据完整策略周期采样，`SAMPLED_IN_BOUNDS`不代表连续物理时间无越界。
- 单图每组两次、全部仅48次。初态仍有自然差异，不能视作严格配对；开发图不是留出图。C−A、D−B等是本批描述性对照，不据此确认H=0.20正式适用、算法一般成功率或参数优越性。是否继续采用H=0.20作正式对照参数，需Director结合代价与本批外证据审阅；本报告不冻结部署默认值、不启动参数搜索。
