# 2026-11-04 只读状态曲线与前置相机

用户要求以图形观看机器人状态并预览之前提到的相机。本轮实现并实际验证[只读窗口](../../../scripts/go2_live_view.py)，运行说明见[观察器文档](../../../scripts/go2_readonly_state/README.md#曲线与前置相机窗口)。未运行控制器、模型或运动，未切换控制权。

## 实现

- 复用SDK2状态观察器，新增显式--json输出模式，每100ms发送最新状态快照；原终端模式保持每秒显示。未收消息输出null，NaN/Inf输出null，不用零值掩盖缺失。
- 新增go2_readonly_camera，只调用VideoClient::GetImageSample获取前置相机数据，采用JSON长度头加JPEG载荷传给界面。相机请求期限2秒，成功后间隔100ms；这不等于已测得相机原始帧率或端到端延迟。
- PyQt5/Matplotlib窗口显示最近约30秒曲线，选择FR/FL/RR/RL查看对应3关节角度、角速度、估计力矩和温度；另显示IMU角速度/加速度、位置/线速度和四足原始力值，以及12关节数值表。
- 状态快照约10Hz，绘图目标5Hz，SDK实际接收频率另行显示。DDS接收时龄与显示样本时龄分别展示。接收超过现有暂定100ms时标注状态过期、曲线留空；界面不承担安全停止功能。
- 相机显示彩色图像和距最近取图成功的本机时长。失败展示真实返回码；不启用其他服务或替代输入。图像不代表深度数据，也不保证与状态同步。
- 关窗、“结束只读监视”或Ctrl+C会向本窗口子进程发SIGINT并等待退出；超时明确报告并结束仅属于本窗口的读取进程。默认不录制视频或全频状态。

## 检查与实际结果

两C++程序构建通过；JSON合成消息检查确认新字段、缺失null和非有限值null转换正确，未初始化DDS。Python语法检查通过。

首次GUI启动在导入阶段失败：用户目录NumPy 2.2.6与系统Matplotlib的NumPy 1 ABI不兼容，尚未创建SDK子进程。使用系统/usr/bin/python3 -s（NumPy 1.21.5、Matplotlib 3.5.1、Qt5）解决；未改动已有Python包。主进程和SDK子进程使用明确的系统/SDK运行库路径，避免Conda运行库遮蔽。

实际短时预览两次，每次16秒自动关闭；第二次用于复核12关节表格完整可见以及显示时龄标签，未进行运动试验。最终12秒快照：状态历史有118个显示样本，相机返回码0，最近JPEG载荷127912字节，可解码，读取线程错误为空。实际图像显示室内场景，已检查合并窗口截图。此结果仅证明本台Go2在当前连接/模式可取彩色图；不证明感知算法或避障可用。

两次窗口退出时，状态与相机子进程退出码均为0。最终核对无本轮GUI或读取器残留；未运行运动控制。
