# 2026-11-04 静止状态实际接口核对

## 范围与状态

用户授权连接Go2 EDU并开展静止接口核对。本轮完成只读字段补全、原生模式查询、32秒采样及数值基础检查；用户随后确认采样时机器人趴在地上，机身略有前后倾斜；App固件版本仍待提供。姿态与静止低力矩、低速度及俯仰约−5°基本相符，但不能据此标记整个物理接口核对通过或进入运动。

本轮没有运行ROS控制器、模型推理或运动；不调用ReleaseMode/SelectMode，不创建LowCmd发布器。一次性CheckMode只查询原生服务。当前唯一ACTIVE任务与仿真配置不变。

## 实现与记录

观察器新增12关节tau_est、温度、IMU加速度以及LowState原始tick/version；复用已有SDK2订阅实现。构建和合成消息回调断言通过（包括新字段数值与打印），未在测试中建立DDS。现有温度字段为SDK uint8，存为数值后打印，避免字符显示。

网络为enp7s0、电脑192.168.123.99/24、DDS domain=0；采样起止电脑时间2026-11-04T13:10:39+08:00至2026-11-04T13:11:11+08:00。观察器运行32秒，SIGINT自动退出，退出码0，标准错误只有启动及正常退出提示。下面统计来自31个约1Hz、数值四位小数的显示快照；不是全频逐条消息统计，接收数/频率/最大间隔为最后显示时的回调累计统计。

## 实际结果

- CheckMode返回0，form=0，name=ai。当前原生服务为ai，未释放。后续有支撑的交还验证应检查恢复进入前模式ai，而不是硬编码normal。
- LowState末次显示累计15503条，平均499.7Hz，最大本机接收间隔6.31731ms。
- SportModeState末次显示累计15435条，平均499.45Hz，最大间隔5.69664ms。
- 显示快照未发现NaN/Inf；SportModeState的stamp持续递增，mode=7，error_code=0。官方ROS2 README把mode=7标为damping；它是SportModeState状态枚举，与CheckMode所查原生服务名称是不同层级，不能据此认为原生服务已关闭。
- 关节角快照中最大峰峰变化约0.0001（接口预期rad，已接近输出分辨率）；角速度绝对值最大0.1201（接口预期rad/s）。不能用这些快照证明逐电机映射、符号和全频稳定性。
- 关节估计力矩绝对值最大0.2474（接口预期Nm）；温度原始数值27–32（接口预期摄氏度），短窗显示稳定。未用厂商未核实的阈值判定承重/运动正常，tau_est不是独立力矩传感器测量。
- IMU四元数范数范围0.999980–1.000018；角速度最大绝对值0.0309（SDK原值）。按wxyz常规公式，末次roll/pitch/yaw约0.51/-4.96/2.07度，尚无实物姿态对照。
- IMU加速度模长约9.394–9.645（接口预期m/s²）。与重力同量级但偏低，不能宣称已完成标定或轴向核验；不据此自动改变策略观测或启动标定工程。
- 位置快照x=-0.0052、y=-0.0008至-0.0007、z=0.0494；三个速度分量显示为0.0000。静止条件下数值稳定不证明运动响应或低层接管后可靠。position.z不直接作为机身离地高度。
- 足端力末次原始值[15, 16, 16, 15]，按当前接口标为FR/FL/RR/RL。单位/零偏和实际接触判别未验证；不能仅凭本次静止读数确认策略现有接触阈值1.0适合实机。
- LowState原始version=[0,0]，不能据此确定固件版本，须由App/设备信息补充。tick在显示快照间推进；机器人stamp与电脑时钟未确认同步，不跨时钟直接计算传感器时龄。
