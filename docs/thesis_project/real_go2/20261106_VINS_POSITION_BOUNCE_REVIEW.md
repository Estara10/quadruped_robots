# D435i/VINS可靠订阅现场位置回摆审阅

日期：2026-11-06。只分析已有CSV、rosbag、VINS日志和源码；未连接相机或Go2，未回放VINS、未改代码或参数。

## 结论

这次约0.436 m的位置变化**先出现在优化odom**，并伴随优化速度明显变化。IMU传播输出短暂继续沿旧状态预测，随后在下一批IMU输出中跳到与优化状态接近的位置和速度。源码中的优化后状态重锚定与本次顺序相符；没有发现独立的坐标转换、消息配对或发布实现缺陷。

因此，现有证据支持“回摆由后端优化状态更新进入传播输出”这一处理阶段判断；**不能判断校正后的位姿是否反映真实相机运动**。没有确认应修的实现错误。输出具备继续做一次受控动态验证的基础，但尚不能作为Recovery或其他控制闭环的可信速度来源。

## 时间对齐与数据

主CSV中的各路`arrival_s`来自同一个采集器时钟，可以互相比较；图表横轴使用消息header时间减去rosbag metadata起始时间。两者分别报告，不把其他进程的steady时钟直接相减。VINS日志中的ROS时间用于粗略对照后端参数和求解耗时。

在采集器115–130 s窗口内，最大相邻优化位姿变化复核为：

| 输出 | 时间与变化 | 速度/姿态 |
|---|---|---|
| 优化odom首次出现 | header elapsed 119.84009→119.97344 s，间隔133.352 ms；同一采集器arrival 120.66551→120.80975 s | 世界位移[-0.36429,-0.24028,-0.00636] m，模长0.43644 m |
| 优化odom twist | 变化前后同一对消息 | child/body系速度由[0.4591,0.0100,0.0348]变为[0.0299,0.0247,-0.0552] m/s；优化姿态差约0.89° |
| 传播odom暂未跟随 | header 119.84105→119.97109 s，位移约0.04861 m | 仍保留约0.48 m/s的body系前向速度 |
| 传播odom追上校正 | header 120.00110→120.00610 s，间隔5.002 ms | 位移跳变0.50719 m；body系vx由0.4803降至0.0285 m/s，跳后位置[0.28318,0.28252,0.20483] m，接近优化odom在119.97344 s的[0.28205,0.28366,0.20542] m |

按同一采集器arrival顺序，120.001 s附近的旧传播样本先到，优化odom校正随后到达，新的传播状态再到达。这说明传播状态**跟随了优化修正**，但跟随过程包含离散跳变。

代码路径是：非线性优化、失败检测和滑窗后调用`updateLatestStates()`，把优化状态的`Ps/Rs/Vs`写入传播状态并重放缓冲IMU；之后IMU回调继续快速传播并发布`imu_propagate`。位置差首先由`/vins/odometry`输出，后续再进入传播输出，符合该重锚定路径。相关位置见隔离VINS源码`estimator.cpp:603-640,1664-1688`、`inputIMU():216-230`；两路Odometry都以world pose发布、以child/body系发布线速度，见`visualization.cpp:69-91,153-174`。本次积分比较按四元数将body速度旋转到world一次。

在header elapsed约115.04–129.97 s范围，优化位置净变化为[0.0726,1.0079,0.1231] m，而优化body速度旋转到world后的梯形积分为[0.6359,1.0496,0.0828] m；传播位移与优化位移接近，传播速度积分为[0.6752,1.0808,0.0800] m。主要差别在world-x方向。优化器会校正状态，传播端也会重锚；速度积分不包含这些离散位置校正，所以差异本身不是坐标实现错误证明，但表明不能把该段速度积分当作位置真值。

## 处理阶段线索与证据边界

- VINS在活动图像范围收到左右图各2023帧，pair=dispatch=2023，无drop；两侧队列最高长度为1。该回摆不是由本次记录中的双目缺图或队列积压解释。
- 初始化已完成；回摆附近日志没有failure、reset、restart或lost记录。优化求解耗时局部范围为1.93–11.62 ms，全程最高19.06 ms，没有秒级求解停顿证据。
- 配置允许`estimate_td=1`。VINS日志的`td`在elapsed约119.062 s从0变为约7.69 ms，回摆后维持约7.676 ms；该变化早于优化位姿变化约0.78 s，是相关线索，不能据此证明时间偏差导致回摆。
- 回摆前约0.58 s，IMU记录出现gyro模长峰值4.678 rad/s及加速度模长峰值13.088 m/s²。双目抽帧显示118.973 s图像被近距离物体大面积遮挡，119.773 s后视野转为房间场景；119.773、120.173和120.974 s的场景视角略有变化，未见足以定因的单帧异常。左右对应header一致。它们支持这段时间相机有显著运动/遮挡的可能，但不提供真实轨迹或姿态。
- `extrinsic_parameter.csv`是运行结束留下的最终外参估计；源码以`FileStorage::WRITE`逐次覆盖它，没有可与回摆逐帧对齐的外参历史。日志有`td`序列，但没有特征数量序列；本次录包也未含VINS track图像话题。

静止背景片段中的body速度接近零：指令前采集器arrival窗均值约[0.0027,0.0046,-0.0185] m/s，末段窗均值约[-0.00045,0.00018,0.00010] m/s。它只说明该两段输出接近静止，不证明动态精度。用户标称1 m参考和终点净位移1.116 m也不能判定中间这次回摆正确或错误；运动边界、用时、相机路径及姿态都没有独立记录。
