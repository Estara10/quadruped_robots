# D435i/VINS 视频参考相机平移采集

日期：2026-11-06。主助手执行相机-only采集，用户提供13.5秒外部视频并确认只做粗略审阅；未连接Go2，未启动机器人控制。采集结束后用户将D435i固定安装到Go2，并报告传输速率由USB3.0降为USB2.0，初步怀疑扩展坞限制；该安装与速率尚未由本轮核实。

## 目的与配置

此前可靠订阅候选已让现场双目连续配对并输出，但一次手持记录出现约0.436 m的后端状态校正，缺少真实运动过程参考。本轮沿用同一候选配置，增加外部视频，用于粗略判断运动方向、量级和停止行为。

- 相机-only，ROS域42、localhost-only；左右红外640×480@15 Hz，gyro 200 Hz、accel 100 Hz，IMU合并方式2，`enable_sync=true`，深度和彩色关闭，投射器关闭。
- 先确认相机图像发布端为RELIABLE，再启动VINS；端点查询确认VINS左右图像订阅为RELIABLE。
- 启动、算法、标定与上一次候选一致；仅替换输出目录。

操作提示：固定手机拍到相机与约1 m路径；相机不动时在镜头视野边缘挥手一次作为同步动作，等待约5秒后保持高度和朝向平移约1 m，终点停留约10秒。**用户事后确认忘记挥手同步动作**，因此视频不能与传感器记录精确对齐。

## 初步结果

采集约70秒，含清理72.09秒；首次优化输出约6.86秒，就绪约11.87秒。左右图各1037张，IMU 13820条，优化odom 475条，传播输出12655条；录包各话题计数与CSV一致。

- VINS接收左右各971张，pair=dispatch=971，无drop事件。每侧多出的66张录包帧均在VINS活动header起点之前；活动范围内没有录包可见而回调缺失的图像。
- 右图回调最大接收间隔77.52 ms；优化odom最大接收间隔147.94 ms、最大header间隔133.35 ms；传播最大接收间隔10.07 ms。本次未复现秒级交付空档。
- 按指令前约4秒位置中位数与末尾约3秒位置中位数计算，三维净位移1.011 m；世界系位移约[0.030,1.011,0.015] m。窗口来自消息时刻，尚未与视频对齐，不能据此宣称厘米级精度。
- 优化输出相邻位置增量最大0.0535 m，对应header间隔约0.133秒；本次未重现上一批约0.436 m的相邻位置变化。
- 无非有限记录；VINS日志没有failure/reset/terminate字符串。
- 收到用户结束消息后，先SIGINT停止VINS，再停止相机，退出码均0、无信号升级；外部进程核对无相关相机/VINS残留。

## 外部视频审阅

视频为576×1280、30 fps、405帧，标称13.5秒；已抽帧查看，未修改原视频。画面可见相机沿桌面移动并在远端停下，过程有手持及姿态变化；起点附近相机部分时间不在画面内。

由于缺少同步动作，未精确对齐视频与传感器时间，不计算瞬时误差，也不从像素推算米制位置或精确速度。视频只能支持“相机/VINS链路运行、运动方向与位移量级初步可行”的描述，不证明位置、速度误差已有保证。

用户明确本轮只需粗略查看，暂不追求高精度；后续固定在Go2后再评价位置、速度的适用范围，具体可接受误差须结合控制用途确定。

## 证据边界与下一步

- 1.011 m是消息窗口下的净位移，不是视频确认的真值；不能据此声称1厘米精度或动态精度通过。
- 未验证安装外参、尺度、时间偏差收敛、IMU标定或Go2基座速度转换。
- 本次仍是相机-only，未连接Go2控制链，未运行策略。
- 相机固定到Go2后，USB链路由机载Orin枚举，电脑不能直接访问该USB设备。后续要么在机载运行相机驱动、把双目/IMU经DDS传到电脑VINS，要么在机载运行VINS；两条路线均未验证。机载为Ubuntu 20.04/arm64/Foxy，当前无RealSense ROS 2驱动，不能直接复制电脑的amd64/Humble二进制。

下一项只推荐：先核对相机固定安装后的USB链路。用户报告速率由USB3.0降为USB2.0，初步怀疑扩展坞限制；需在机载Orin上只读确认实际协商速率、经过的hub/port和可用profile，并判断USB2能否满足当前双IR+IMU配置及后续深度需求。核对前不更换线缆或扩展坞、不安装驱动。核对后，再确定相机驱动与VINS的运行位置（机载或跨机），之后才安排电脑只读、原生遥控的受控低速运动观察。

**后续（2026-11-06）：**只读核对已完成：相机在Bus 01、协商480Mb/s；换线绕过USB2 Hub后仍为480Mb/s，Bus 02的10000M根口未使用。限制在端口/上行链路或线缆，当前无已确认的USB3路径。当前双IR+IMU带宽约9MB/s，USB2原则上可容纳；下一步按USB2确定机载驱动与跨机传输方案，不据此宣称USB2已满足全部用途。详见[机载只读检查](20261106_ONBOARD_D435I_READONLY_CHECK.md)。
