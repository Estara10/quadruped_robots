# D435i 投射器开／关静态对照

## 针对什么问题

有线接收稳定后，真实深度帧仍有41%–46%零值。本轮检验关闭红外投射器是否是本场景大量缺失的重要原因。完成条件是取得相同profile、相同场景与姿态下的开／关数据，比较缺失比例及接收连续性，不接策略。

用户确认机器人保持趴伏。本轮未发送站立、运动、停止、控制权或模式切换命令；未启动VINS、控制器、策略或Viewer。

## 做了什么

在有线链路上顺序运行两个独立相机采集窗口，每次唯一pipeline：

- PC enp7s0 `192.168.123.99`，Orin eth0 `192.168.123.18`，CycloneDDS、ROS域42；两端接收上限保持8MiB。
- 深度＋双IR：480×270@15；gyro 200Hz、accel 100Hz、合并方式2；同步开启，诊断周期1s。
- 复用已有观察器，每个窗口30s；实际收流约28.6／28.8s。相机外层限时36s，先于相机启动建立电脑订阅。
- 唯一计划改变的相机参数是 `depth_module.emitter_enabled`：先0、后1。现场参数查询分别返回0、1；两次laser_power均为150.0，未调整功率。IR图像中开启阶段出现清晰点阵，确认投射器实际工作。
- 各阶段独立启动，启动暂态和自动曝光可能不同；统计时统一排除收到首张深度后的前5s。没有改变曝光、深度预设、分辨率、QoS、模型或补洞算法。

采集目录：[20261111_071641_d435i_emitter_ab](../../../logs/real_go2/20261111_071641_d435i_emitter_ab/)。其中保存准确运行脚本、参数回读、原始帧、逐帧CSV、接收统计、退出状态、UDP统计、分析脚本和JSON。

## 结果

| 项目 | 关闭投射器 | 开启投射器 |
|---|---:|---:|
| 深度接收数 | 431 | 434 |
| 深度接收频率 | 15.014Hz | 15.015Hz |
| 深度最大接收间隔 | 74.74ms | 81.84ms |
| 排除前5s后的深度帧数 | 356 | 358 |
| 零深度平均比例 | 46.73% | 26.04% |
| 零深度比例中位数 | 46.99% | 25.84% |
| 零深度比例范围 | 42.13%–50.44% | 24.73%–28.21% |
| 左／右IR接收数 | 429／429 | 432／432 |
| 左／右IR频率 | 约15.016Hz | 约15.016Hz |
| 合并IMU接收数／频率 | 5734／199.991Hz | 5802／199.984Hz |
| Frame resources错误 | 0 | 0 |
| PC UDP接收错误／缓存溢出增量 | 0／0 | 0／0 |

开启后缺失减少 **20.69个百分点，相对减少44.27%**。IR图中的柜门、纸箱等表面有了点阵，深度完整度明显改善。两阶段都没有秒级收流中断或Motion Module failure；IMU默认标定警告仍存在，IMU数值质量及VINS跟踪不在本次测试范围。

最后帧仍有25.47%零值；开启投射器没有消除所有空洞。保存的4张开启帧未见大于6m或65535值，关闭帧仍有少量极端值；这只是本次样本统计，不据此判定全部有效像素准确。

## 判断与后续

**关闭投射器是这个场景大量深度缺失的重要原因；当前问题是测距质量，不是有线图像接收中断。** 本轮支持将投射器开启作为深度质量候选设置，不将其直接设为整套VINS＋ABS的默认配置。

剩余约26%空洞的位置和成因尚未逐项区分。不能把所有空洞都当成无障碍，也不能因补洞后数值齐全就认定射线有效。已有诊断显示不同补洞方式可导致约0.96m预测差，见[真实帧射线诊断](20261111_REAL_DEPTH_RAY_DIAGNOSTIC.md)。

下一步先离线检查本次开启投射器帧中剩余空洞的分布，限定预处理范围并核对视场；在联合相机配置确定前，还需检查点阵对VINS特征跟踪的影响。本轮没有追加该测试，没有验证深度准确度或ABS避障能力。

## 收尾

两次观察器退出0；相机外层timeout均124（计划限时），日志确认SIGINT后关闭两个传感器。开启阶段观察结束后将emitter参数恢复0，返回 `Set parameter successful`，随后关闭相机。未改相机启动配置或系统持久设置。

参数查询新建了Orin域42的ROS daemon；确认来自本次后单独停止，再次检查PC和Orin均无相机、观察器、VINS、rosbag或ROS daemon匹配进程。分析正常结束。未修改模型、控制器、仿真或R1任务，未提交Git。
