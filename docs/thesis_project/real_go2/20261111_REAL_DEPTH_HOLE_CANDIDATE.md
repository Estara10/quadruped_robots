# 投射器开启后真实深度空洞：最小离线候选

> 后续现场观察：用户换位置并站立后，在相同profile、投射器开启条件下，全图平均零值降至7.41%，中央ROI平均98.33%有效。场景与姿态同时改变，不能单独归因。下文结论只针对原柜门场景的四帧，不将其扩展为所有真实深度都不适合只读验证；后续优先用更完整的新帧做输入适配，见[现场记录](../../../logs/real_go2/20261111_075040_d435i_new_position_standing/RESULT.md)。

## 针对什么问题

投射器开启后，D435i静态观察的零深度比例从46.73%降到26.04%，但严格ABS射线适配器仍拒绝输入。此前不同补洞假设造成约0.96m的最大射线差异，不能把任意填补结果送入控制。

本轮检查剩余空洞形状，并只试一个局部候选：仅填被实测深度完全包围的孤立单像素洞。原严格入口和默认行为不变。

## 代码与数据依据

- 四张输入均为 `logs/real_go2/20261111_071641_d435i_emitter_ab/on/` 内ROS `16UC1`副本，uint16单位毫米，按 `depth_m = raw * 0.001` 转换。原始文件未修改。
- 严格下采样复用 [`realsense_depth_to_abs_rays.py`](../../../scripts/realsense_depth_to_abs_rays.py)：160×90中心采样，检查每个3×3源足迹；只要其中含一个无效像素，该模型像素仍标为无效。原适配器拒绝这类输入。
- 仿真/微调预处理使用米制深度裁剪到[0.1, 6]后取`log2`，并复制成三通道；见[`ray_predictor.py`](../../../scripts/ray_predictor.py)和[`finetune_mujoco_ray_pred.py`](../../../scripts/finetune_mujoco_ray_pred.py)。训练数据没有建立“零值代表无障碍”的契约。训练增强里随机擦除的0.25m/6m是增强值，不是实机空洞语义。
- 所用微调模型清单指向 `mujoco_ray_pred_medium_20260611` 与 `mujoco_ray_pred_near_20260611`；两份实际微调数据清单都记录生成视场102°。本次相机深度CameraInfo的水平视场约88.9°。因此102°有这些仿真微调集的清单依据，但不是本机相机视场；更早的基础模型原始训练视场没有在本轮确认。不能通过拉伸深度图补出相机未观测到的角度。
- 最后一张深度图与保存的IR1/IR2具有相同header时间戳。IR可见柜面、箱体上的投射点阵及较暗的边缘区域，但IR像素与深度像素注册没有在本次记录中单独确认，故只作场景背景，不将某个零值区域归因于反光、遮挡、距离过近或其他具体原因。

## 空洞分布与单一候选

以8邻接连通域统计，四帧零值占25.47%–27.49%。其中73.55%–78.45%的零像素属于接触图像边界的连通区域；每帧最大零值连通域约8,409–9,395像素。空洞呈边界成片缺失并夹有较大的内部区域，不是以散落小点为主。空间分布在四帧中大体稳定，详见下方频率图。

候选规则：仅当一个8邻接无效连通域恰为单像素、位于图像内部且周围8个像素均为实测值时，以8邻域中位数填该像素。填充值单独保留来源掩码。它是局部连续性假设，不代表测得的距离，也不处理成片空洞。

每帧该候选只填250–279像素，即原零值的0.71%–0.79%。按严格3×3足迹缩小后，未知模型像素比例只从41.11%–43.87%降到39.56%–42.13%。大片未知区域仍在。

## 结论与下一步判断

- **空洞位置：**主要是触及图像边界的大片连通缺失，并有较大内部区域；IR可见投射点阵，但不足以诊断空洞成因。
- **可处理部分：**孤立单像素洞可作局部候选，填补量不到零值的1%。其余区域继续标为未知。
- **是否进入下一次只读射线验证：**当前不值得把整帧11束输出当作有意义的实机射线验证。严格输入仍有约40%缩小像素未知；让模型输出完整值必须给未知区域加入假设，而输出会依赖这些占位。此次诊断输出明确`prediction_valid_for_control=false`。
- **主要阻塞：**大块深度未知没有得到有物理依据的填补语义；单像素修补无法解决。不得把剩余未知统一填成远距离或近距离后接入ABS。真实深度精度、相机/训练视场适配和投射器对VINS的影响仍未验证。

本轮未连接Go2、Orin或相机；未初始化ROS/DDS；未启动VINS、控制器、策略或共享内存发布；未修改严格适配器、模型、仿真、R1任务或go2_navigation。仅新增一次性离线诊断脚本、JSON、图和本报告；分析进程已退出。
