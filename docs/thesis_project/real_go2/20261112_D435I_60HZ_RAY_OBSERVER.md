# D435i 60Hz深度→ABS射线只读观察器准备

## 目标与实现

为现场测量深度接收频率、实际射线输出频率、预处理/推理耗时和处理积压，新增独立入口[`go2_depth_ray_observer.py`](../../../scripts/go2_depth_ray_observer.py)。它只订阅已有`/camera/camera/depth/image_rect_raw`及CameraInfo，不开SDK pipeline，不发布协议帧、共享内存或控制数据。

在线回调只记录输入header、电脑单调接收时间和图像元信息，并将消息放进一个最新待处理槽。若推理时新帧到达，未处理的旧待处理帧被覆盖并计数；正在推理的帧完成后取最新一帧，不重复消费旧帧。处理线程复用已有`source_valid`计算全图零值比例，以及原图ROI `x=[220,260), y=[115,155)` 的40×40零值比例。CSV记录接收、处理开始/结束、这两项比例、排队、预处理、推理、总耗时、未知比例及11束诊断输出；JSON汇总接收/输出频率、最大间隔、覆盖数、两项比例的处理帧分布、末帧时龄和CameraInfo。没有可靠跨机对时，header与电脑单调时钟不相减，跨机采集时龄留空。被最新帧槽覆盖且未进入处理的图像不扫描零值，只计入覆盖数。

仅接受已测的`480×270 16UC1` ROS深度，单位毫米、乘0.001转米。NumPy向量化采样与当前中心像素位置完全一致；候选有效性只看被采样中心是否有效，同时记录原3×3全有效规则。未指定`--unknown-fill-m`时，存在未知中心的帧跳过推理；指定后未知格只在诊断张量中临时占位，所有输出仍标`prediction_valid_for_control=false`。默认观察30秒；现场为覆盖36秒相机运行可显式用42秒。只保留当前推理帧及一个待处理ROS消息，不保存图像。

## 离线验证

复现命令见[脚本说明](../../../scripts/go2_depth_ray/README.md)。本轮用系统Python、既有TorchScript模型和4张已保存深度帧运行`--offline-self-check`，未source ROS、未导入rclpy或初始化DDS：

- 四帧向量化中心样本与原适配器样本逐项一致；严格3×3掩码逐项一致。
- 四张保存帧均输出全图/中央40×40零值比例（全图7.45%、7.57%、6.94%、7.43%；ROI 2.31%、1.88%、1.94%、0.63%）；检查计算复用`source_valid`，未改变模型输入。
- 4次显式0.1m占位的有限模型推理均输出11个有限距离；本轮CPU推理约12.1–39.1ms，单次预热约72.7ms。首帧耗时包含冷启动因素，不能当持续频率保证。
- 合成慢处理线程收到1、2、3、4时处理1和最新4，待处理覆盖计数2，处理后无旧帧重放、无残留待处理帧。
- 用单条合成处理记录检查CSV逐帧两字段与JSON分布字段均正确写出；现场未运行。
- `--help`可运行；离线检查不初始化DDS，不保存图像、协议帧或共享内存。

本轮没有运行在线ROS订阅，因此真实接收/推理频率、QoS交付和60Hz积压仍待现场测。只读槽只限制回调已交付后的用户态待处理帧；不控制DDS内部缓存。全量模型输入仍有未知中心，0.1m是假设占位而非实测，也不保证网络输出保守。

## 模型与现场边界

当前相机CameraInfo推算水平视场约89°；当前微调数据清单及仿真预测配置记录102°。输出角度合同仍为−45°至+45°，本轮不拉伸/补边、不改角度或模型。可以进行有限的只读吞吐/重复性观察，但输出不代表已校准的物理射线或避障准确度。中央约2.03m相机读数不是测距真值；若评价射线距离，还需独立测量障碍方向和距离。投射器对VINS的影响不在本轮范围。

## 下一次相机只读观察

准确命令和输出位置见[现场操作说明](../../../scripts/go2_depth_ray/README.md)。运行前由主助手只读确认历史接口仍适用：PC`enp7s0 / 192.168.123.99`、Orin`eth0 / 192.168.123.18`、CycloneDDS、domain 42、无其他相机节点占用。由PC启动观察器后，在另一终端启动一个480×270@60的Depth＋双IR pipeline，gyro200/accel100、合并方式2、投射器开启、RGB关闭；限时36秒，观察器运行42秒覆盖启动和结束。

检查深度约60Hz、11束输出节奏、未知比例、队列覆盖、最大间隔、预处理/推理/接收到完成耗时及CameraInfo。profile不符、输入无效、持续停收、异常输出或主助手要求停止时结束并保留日志。操作者先结束相机与采集；观察器本身没有机器人停止能力。该测试不启动VINS/控制器/策略，不证明真实障碍距离精度，也不证明VINS＋射线联合60Hz可用。

本轮未SSH、未访问相机或机器人、未初始化DDS、未改系统配置/模型/仿真/R1/go2_navigation。唯一ACTIVE任务未改。离线自检进程已退出，临时绘图配置目录已清理。
