# 新D435i原生SDK补洞实测

日期：2026-11-12。本轮只回答：在Orin实际librealsense 2.51.1中运行mode 1，能否减少空洞、保持60Hz，以及结果是否与已有离线候选吻合。

## 实施与结果

替换机238322070866，固件05.13.00.55，USB2，单pipeline深度-only Z16 480×270@60Hz；scale=0.001m/单位。投射器、自动曝光开启，laser power=150。约3秒预热后，连续约6秒对360帧逐帧应用SDK原生`hole_filling_filter(1)`。仅保存第0、120、240条的3对原始/补洞帧，不保存全部图像。

| 指标 | 原始 | 原生补洞后 |
|---|---:|---:|
| 全图零值均值 | 4.973% | 2.281% |
| 中央40×40零值均值 | 0% | 0% |
| 原始有效像素改动数 | — | 0 |

原始空洞中约54.12%被填入；同一处理循环接收59.906Hz，最大本机接收间隔17.286ms，frame_number无缺号。该结果是相机采集加补洞循环的本机接收表现，不是ROS跨机或ABS完整链路延迟。实际曝光9703µs、gain=16。

3张补洞样本映射到160×90后，中心采样未知比例为2.063%、2.160%、2.306%；严格3×3足迹未知比例为2.382%、2.868%、2.736%，当前严格入口仍全部拒绝。本轮未填6米、未推理射线、未写共享内存。

原生补洞能减少空洞，本次没有破坏原有效值或使处理循环跌离60Hz；仍有约2.28%未知，不能仅凭填补比例评价11束预测准确性。下一步可直接使用本轮3对数据离线运行“原生补洞＋残余6m占位”的射线诊断，与原始直接6m占位比较。生产适配器、模型和控制行为保持现状；视场合同和未知拒绝条件按已安排任务处理，不直接接ABS控制。
