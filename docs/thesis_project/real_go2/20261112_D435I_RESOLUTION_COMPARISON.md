# D435i静态分辨率对照（2026-11-12）

本轮问题：提高采集分辨率是否能减少当前场景的深度空洞。结论：本次共同6Hz对照没有改善，1280×720的零值比例更高；继续以480×270@60Hz推进已安排的原生补洞离线评估。

## 方法

Orin现有librealsense 2.51.1、USB2、替换机238322070866、固件05.13.00.55；只开一个深度Z16 pipeline，不启动ROS、VINS、模型或机器人控制。要求相机位置、朝向及场景不变，顺序为480×270@60、480×270@6、848×480@6、1280×720@6。每档预热约3秒、记录约6秒，保存3张原始深度，全部约9.2MiB。

设备实枚举支持480×270@60/30/15/6、848×480@10/8/6、1280×720@6，以及其他档位；480×270没有10Hz，因此选共同6Hz隔离帧率差异。枚举不等于其他联合流组合已实测。

测试均开启投射器、自动曝光，laser power=150；depth scale=0.001m/单位。内参计算水平视场均约89.02°。中央区域采用相同归一化范围，480×270时是x=[220,260)、y=[115,155)，高分辨率按比例取整。未使用任何补洞、空间或时间滤波。

四档记录中的连续frame_number均无缺号。帧率依据本机steady_clock接收时刻计算，不是PC跨机ROS收图频率。采集CSV的device_ms列因默认数值输出精度不足发生量化，不能用它计算帧间隔；分析已改用有足够精度的host_s，原始CSV保留。此问题不影响像素统计、样本或帧号。

自动曝光实际值约9233–9703µs，gain均16；没有假设曝光严格相同。每档是一次顺序短观察，没有独立重复，不能把全部差异唯一归因于分辨率。图中高分辨率显示更多边缘细节和细小未知区域；本轮没有平面距离真值或小障碍标签，不评价深度精度优劣。中央中位数约2.7–2.9cm的变化也不是已确认测距误差。

## 对ABS的影响

本次没有得到提高分辨率可减少空洞的收益，也没有依据为此牺牲60Hz。保留480×270@60作为当前候选，继续对已有数据比较原生补洞与直接6m占位。高分辨率可能改善细节或测距精度，但这是另一项问题，本轮不追加实验。

本轮没有运行射线模型、写共享内存或接入ABS，不改变严格适配器。候选是否适合ABS输入，仍按既定离线补洞比较与后续静态射线核对判断。
