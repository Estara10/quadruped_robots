## 当前模型结论

原有射线网络训练过，但没有完成当前安装和D435i输入条件的适配。新pilot使用旧medium初始化、768张合成输入、固定4轮：留出MAE由2.113m降至0.966m，近障高估≥0.5m由98/360增至121/360。其生成数据后来发现主点偏移，原指标/权重保留为开发记录，不作为完全匹配实测内参的通过结果。

主点问题已修正并做小批几何检查；没有再训练或覆盖生产模型。首次合并渲染/训练进程在结果写完后清理异常退出134，独立加载候选复算正常退出0，根因仍未定位。

当前安装下部分近侧测点落在画外，需分组评价能力边界，但“全部11束交点都必须在画内”不作为候选训练的绝对前提。画外交点不等于整个障碍不可见，完全未成像的目标也不能靠加训练承诺恢复。暂不要求移动支架；用户提供的ABS原作者照片同样显示相机在机身前上方，照片本身不能提供精确外参或证明两套几何完全相同。

## 后续方向

1. **模型准备继续：**保留当前安装候选，修正后的数据增加近障、左右方向和远处覆盖，按完整布局留出。先改善可见目标预测，再明确画外信息的限制；选模型同时看总体误差与近障高估，然后安排服务器有限训练。精密机械外参不是所有离线候选准备的前提，不为清零所有未知无限暂停。
2. **空洞按正常缺测处理：**优先复用SDK邻域补洞，不追求原始图100%有效；保留残余未知，不把补值或填6m直接当作已验证的控制输入。
3. **相机测距单独收尾：**后续同一平整目标、明确的尺量起点和中央测点复核约2m差异，不能让网络训练掩盖相机偏差。
4. **USB3列后续优化：**需要高分辨率与高帧率同时运行时再排查扩展坞链路。当前先复用已观察到的480×270@60Hz，不把USB2当作模型短预测的已证实根因。
