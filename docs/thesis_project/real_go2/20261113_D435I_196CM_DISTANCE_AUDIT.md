## 结论（通俗）

1. **代码读取没有发现能解释这12.8cm的错误。** 原始文件的尺寸、字节序、比例尺（0.001m/单位）、中心像素索引(240,135)、保存帧号与`frames.csv`一致；补洞文件在中心像素没有改动原值；marker里的Z和原始文件一致；时间戳与同帧深度完全一致。
2. **中心像素落在柜门一个连续表面上**，不是空洞、门缝或把手。中心15×15像素深度从2.055平滑过渡到2.122m，没有跳变。三帧读数2.099/2.099/2.110m；360帧单像素中位数2.088m（P5–P95 2.055–2.122m）。
3. **Z深度、直线距离、水平距离三者在这里几乎相等**：中心像素离光轴只有1.23°，直线距离比Z大0.05cm；地面拟合显示光轴相对地面只差0.86°（近水平），所以"俯角/水平投影"最多解释不到0.1cm，不能解释12.8cm。
4. **测点映射本身不构成误差来源**：中心邻域坡度约2–3mm/像素，即使IR与深度有10像素错位，Z也只差约2–3cm，不足以解释12.8cm。
5. **剩下两类可能：卷尺起点/终点参考点偏了约11–14cm，或相机把距离读大约6.5–7.7%。现有数据不能把两者分开。** 缺少的关键信息是：卷尺近端到底压在哪个结构面上、远端到底落在柜面哪一点，以及第二个距离下的同一参考点复测。

本次确认卷尺红十字测点约**196cm**（人工近似，未标定起点），不再使用此前约193cm的说法，也不把196cm当作11束机身射线的真值。

## 几何复算

使用`metadata.txt`内参fx=fy=244.134、ppx=245.186、ppy=134.22：

- (240,135)在光轴左侧5.2像素、下方0.8像素；Z=2.099m时反投影X=−4.46cm、Y=+0.67cm，直线距离2.0995m，**距离−Z只有0.05cm**。
- 对本帧下半部地面（原始有效点）拟合平面：相机光心到地面垂距0.2487m，光轴相对地面法线89.14°，即**光轴只偏离水平0.86°**。因此水平距离=Z×cos(0.86°)，与直线距离相差<0.1cm；"卷尺是水平投影"这一解释在几何上不成立（要解释12.8cm需要约20°俯角，与实测不符）。

- 柜门区域原始Z分布（第0帧）：P1=1.972m、P5=2.044m、中位数2.088m、P95=2.133m。卷尺1.96m落在整个柜门深度分布的左尾附近，而不是中心测点附近。

## 仍缺什么 / 一次最小补采

要真正分开"参考点偏"和"相机偏大"，只缺两件事：

1. 卷尺近端的**标记点**：在相机外壳前端或镜头参考面上贴一小段胶带作标记，之后所有距离都从这个标记量起，并拍一张近端照片。
2. **第二个距离**：同一趴伏姿态、不动机器人，在相机正前方约1.0m处放一块平整硬板（书/白板），让板面落在画面中心；用同一标记点和同一把卷尺量一次，同时保存一帧深度＋IR。

判读方式：若1.0m和约2.0m两处都是"深度比卷尺大几乎相同的**绝对量**"→起点/参考点偏；若是"越远差得越多、约成比例"→相机尺度偏置（可由两点定量）；若两处都基本一致→本次196cm是参考点问题。一次静态采集即可，不需要多组测试，也不需要动机器人。
