# 当前D435i射线模型有限适配：低估减轻，但近障高估增加

> 后续离线审阅更正：发现显式相机渲染只设置一只虚拟相机frustum，旧数据实际主点未完全匹配实测K。下文原指标不改，仅作旧生成分布上的开发记录；生成器已修正、未重训，见[失败样本审阅](20261113_D435I_RAY_FAILURE_REVIEW.md)。

## 结论

用户在848×480@10Hz对照未见测距改善后，明确要求开始处理射线模型预测偏短。本轮完成一次固定4轮的ray-only候选微调，不涉及Agile、RA、Recovery训练，也不开展正式论文实验或实机控制。R1保持唯一ACTIVE。

**新候选不能用于控制。** 独立留出的两个合成布局上，平均绝对误差由2.113m降至0.966m，整体低估偏差减小；但真实标签≤1.5m、预测高估≥0.5m的束由98/360增至121/360。近障安全方向没有改善，不以平均误差下降宣布模型可用，没有继续加轮数或反复搜索参数。

## 数据与安装候选

复用已检查的投影与标签代码，原生480×270渲染，再中心采样160×90。实测内参fx=fy=244.134、ppx=245.186、ppy=134.22；实际采集记录了零畸变系数、深度与IR1相同内参、二者外参为单位变换，故无需继续把K对应哪路图像列作本轮未决项。

安装采用壳体中心代理位置base前0.305m、左0m、上0.140m，base高度随机0.35–0.36m、下俯角随机3–5°，覆盖用户报告范围。壳体到光学中心的细小偏移及精确姿态仍是近似，未启用生产外参配置。所有模拟样本以站立几何生成。

6个新建的平地静态布局包含墙、箱体、圆柱、开阔和遮挡条件，均在本轮logs中生成，没有修改共享仿真地图。3个训练布局、1个验证布局、2个最终检查布局，每布局64个合格姿态；排除位于障碍内部或正向射线小于0.45m的姿态。不同集合不共享布局或姿态。384个几何姿态各有clean和masked两个输入，共768张：训练384、验证128、最终检查256。clean/masked配对不跨集合。

11束标签完全从既有ABS几何合同计算：body水平面、−45°到+45°每9°，起点base前向−0.05m，距离0.1–6m。不是网络自身预测标签，也不是相机中心深度。

## 空洞与预处理

训练组使用重装柜前保存的3张原始零值掩码；验证组使用1m组3张；检查组使用80cm和第二次约2m组共6张。集合间无同一原始掩码帧。把真实原图零值掩码施加到模拟原生Z16，再用已有source-equivalent librealsense 2.58.4 mode 1实现补洞，残余0填6m；最后中心采样、裁剪0.1–6m、log2、复制3通道。该离线实现此前与有限2.51.1现场保存样本逐像素相同，不能扩写成所有输入/版本等价。

这是候选输入政策，不是未知像素已经变成真实6m测量。保留clean对照，原始掩码来源与残余未知比例在data_records.json；没有增加模型输入通道或改共享内存协议，默认严格实机入口未改。掩码移植不模拟实际场景深度、材质、遮挡与空洞形成的物理关系，不能代表相机全部空洞分布。

## 固定训练安排

- 起点：`archive/ray_pred_finetune/mujoco_finetune_medium_20260611/ray_pred_mujoco_finetuned_best.pt`，旧权重未覆盖。
- 仅更新ResNet layer4及fc，冻结此前层与BatchNorm运行统计；保留11维输出。
- CPU，batch 16，AdamW lr=1e-4，固定4轮；复用既有weighted_ray_loss，near_weight=4、false_safe_weight=8、false_danger_weight=0。
- 按验证集MAE选出第3轮；最终检查集不用于选轮数/权重。原检查结果及4轮历史完整保留。
- 代码基线commit为`1b87dd1`，使用当前工作区相机几何修改和新候选运行器。Torch 2.0.1、MuJoCo 3.2.3；CUDA不可用。本轮是开发候选，不冻结正式实验版本。

## 运行异常与收尾

最初在一个Python进程中连续运行EGL渲染、训练和推理，已完成4轮、保存RESULT.json并打印DONE，随后解释器退出时出现`free(): invalid pointer`，退出码134。根因尚未确定，不将这次运行写成正常退出。

随后在不创建MuJoCo渲染上下文的独立进程重新加载候选，对全部256张最终检查图重算，MAE和近障高估计数与原保存结果一致，退出码0；因此已保存权重可读取、结果可复算。另一个仅渲染进程检查本轮新增native返回分支，形状270×480、已知墙面采样1.64979m且正常退出。没有重训来替代或掩盖原134异常。

运行器现把生成与训练放在两个独立进程，减少EGL与Torch生命周期交织；只验证了独立渲染及独立权重推理正常退出，未重跑完整分阶段训练，不能宣布内存释放问题根因已修复。当前所有本轮执行会话均已退出，未连接设备、初始化ROS/DDS、运行VINS或控制、写真实共享内存。临时绘图缓存已清理，原数据保留，未提交Git。
