# D435i当前安装候选适配数据 v2（2026-11-16）

## 结果

`adaptation_v2_current_mount` 已完成：1200个机身位姿、2400张clean/masked配对输入，按完整MuJoCo布局拆分为train 840、validation 180、test 180。每个split均通过输入有限性/形状/范围、11维有限米制标签、配对标签一致和集合布局隔离检查；没有空深度输入。生成约200秒；包含诊断/布局文件共2429个文件，文件总量143,083,860字节（约143.1MB，磁盘占用约146MB）。未训练、未推理或比较模型。

当前候选使用左IR前玻璃参考 `(0.300,+0.020,+0.132)m`、下俯3°、base高度0.348m，以及实测K `480×270, fx=fy=244.134, ppx=245.186, ppy=134.22`。这些是有误差的生成候选，不是精密外参：偏航/侧倾按0假设，z来自简化URDF，玻璃参考至内部光学中心偏移未测。

## 生成器修改

修改`scripts/prepare_d435i_ray_adaptation_data.py`：

- 增加相机位置、俯角采样范围、base高度范围、深度内参和测试布局集合参数；默认值保持原`adaptation_v1`相机参数与布局。仅接受当前配对掩码流程支持的480×270输入。
- 新增`current_mount_v2`测试布局集合，两套新障碍布局取代旧`test_mixed/test_open`；train/validation布局保持旧规模和分割。当前新测试布局没有参加`adaptation_v1`的训练、选模或测试分析；没有随机拆分旧帧。mask增强仍复用既有按split隔开的实拍零值掩码库，测试掩码图案不是新采集。
- 几何检查改为使用传入相机候选。相机横向偏置时，机身0°射线投影不必落在`ppx`，故不再错误要求它必须正好居中；左右方向和标签仍检查。
- 米制深度中心采样后再次clip到0.1–6m，射线标签`exp2`后也clip到ABS范围。探针发现float32的6000mm回转值会成为`6.0000005`；这是数值边界，不改变数据物理意义，但此前文件并未严格落在范围合同内。
- 数据生成结束后审计数量、train/validation/test布局不相交、配对文件/标签、有限值、90×160形状、0.1–6m输入范围、11束米制标签范围及空帧。
- 生成前探针使用48个位姿、96张配对输入，约12秒完成；它发现并促成了上述6m浮点边界修正，重跑后通过。探针输出约5.9MB，未保留临时目录。

底层渲染、中心采样、模型预处理、几何标签与SDK mode 1源等价补洞实现仍复用既有代码；未改权重、控制器或策略。补洞候选为：合成深度米值量化到毫米Z16 → 逐split真实零值掩码移植 → librealsense 2.58.4 mode 1源等价补洞 → 残余零值替换6m → 480×270中心采样`(3i+1,3j+1)` → clip 0.1–6m → log2/复制3通道。它对应已记录的候选数值流程，不等于默认严格实机入口已接受；6m值不是实测空旷空间。mode 1增强不是D435i空洞物理仿真。

## 后续使用边界

- `adaptation_v1`原始数据、权重、选模和测试结果均保留。本v2 test使用新场景几何和随机位姿，但仍复用已有test split的零掩码来源；它可作为未参与此前模型比较的新布局留出集，不能描述为包含全新相机缺陷模式的独立实测测试集。
- 新集仅用于后续训练准备；不能现在查看其模型误差再改配置并继续称它为未见测试。下一次模型比较须在预先冻结规则后使用。
- 新布局的画外完全不可见部分、相机与base的安装误差、6m残余未知处理可信度都未解决。任何模型成绩不等于实机安全或控制许可。
- 数据集已具备进入下一轮训练计划评审的条件；训练前仍应按`20261116_D435I_TRAINING_SELECTION_REVIEW.md`预先冻结选模规则，并把本v2 test留作最终留出集，不用它调参。此训练准备不需要机器人；若要收紧实际安装几何，需之后在静止实机上确认安装姿态与参考点。

数据目录：`logs/real_go2/20261116_d435i_ray_adaptation_data/adaptation_v2_current_mount/`，其中`summary.json`含参数、分割、分布、可见性及审计，`data_records.json`记录每个位姿与mask来源，`ray_projection_visibility.csv`保留逐束投影/可见性，`data/{train,validation,test}`保存米制160×90配对与`label.pkl`。旧`adaptation_v1`未覆盖。
