# D435i当前安装下的射线训练几何小批检查（2026-11-16）

## 结论

用现有MuJoCo渲染器、中心采样器和ABS几何标签代码，按当前安装候选生成了9个单目标clean场景；同一场景分别用当前相机候选和epoch3名义几何渲染，共18张原生深度及18张160×90输入。11束机身射线标签在相机配置变化前后完全相同，目标命中距离均与指定几何距离一致。投影左右方向正确。

生成路径能表达当前安装，未发现投影、采样或标签实现错误。可进入“更新训练数据准备”，但不据此直接扩大到全量或启动训练：epoch3的适配包装脚本仍把相机参数写成固定常量；当前安装的偏航、侧倾、壳体至光学中心偏移仍未知。应先让数据生成包装脚本显式接收当前安装候选，再生成按场景隔离的小批新数据核对。真实11束准确度需要另有安装后静态实测参考。

## 本批输入与复现

- 当前相机候选：左IR前玻璃代理 `(0.300,+0.020,+0.132)m`，下俯3°；偏航/侧倾假设为0。
- 对照epoch3名义几何：`(0.305,0,+0.140)m`、下俯4°。epoch3训练实际随机范围为3–5°，base高度0.350–0.360m；本批为了隔离相机变换，两者均固定同一base高度0.348m，因此不是逐个复刻epoch3训练样本。当前base高度也是简化几何估计。
- 两边使用同一实测K：480×270，`fx=fy=244.134, ppx=245.186, ppy=134.22`。深度为MuJoCo干净米制Z值，无补洞或空洞增强。
- 9个几何目标：正前方0°的0.60/1.50/3.00m宽竖直平面；±18°的1.20m、±36°的1.80m、±45°的2.00m有限盒体。每个目标单独成景。
- 复现：

  ```bash

  MUJOCO_GL=egl /home/lidio/anaconda3/envs/abs/bin/python \
    logs/real_go2/20261116_current_mount_ray_generation_check/run_geometry_check.py
  ```

## 检查内容与结果

ABS标签沿用`compare_ray_pred.py`：起点`(-0.05,0,0)m`，在base_link水平面内；11束角从−45°到+45°，每9°一束，索引0为−45°、索引10为+45°，标签为0.1–6m范围内的米制水平射线距离。正角沿机身`+y`（左侧）。`prepare_d435i_ray_adaptation_data.py::target_xml`建立几何目标，`compute_geometric_ray_log`计算标签，`visibility_rows`再用MuJoCo `mj_ray`独立核对每束距离并用分割图判断交点与障碍是否可见；本批198条束记录均通过标签核对，所有预设目标束与目标距离误差小于1mm。

深度流程复用`generate_mujoco_ray_dataset.py::render_depth`：按原生K渲染480×270，再使用既有中心采样`(3i+1,3j+1)`生成160×90米制输入；输入合同后续仍为clip 0.1–6m、log2并复制三通道。本批另保存该log2三通道张量，抽查全18个样本重算最大差为0，张量尺寸和有限性符合合同。没有运行网络推理。

这批直接展示了两种不同情况：当前−36°射线的精确交点略超右图边界，但障碍盒仍有7,261个图像像素；±45°目标则交点画外且整块目标均无像素。画外交点不等于整块障碍不可见；整块不可见的距离不能从该深度图直接恢复。

相同场景下，两配置的11束标签最大差为0；因为机身和场景几何相同，标签与相机位置/内参无关。当前与epoch3的160×90米制输入每样本平均绝对像素差均值为0.076m，最大单像素差为5.276m（偏置障碍/背景边界区域）；这是视点变化导致的渲染输入差，不是网络误差或精度证据。中心方向投影变化也符合候选外参：当前左IR玻璃代理比epoch3名义位置右移20mm，中心束目标像素偏右约2–19px（近目标位移最大）；pitch、高度共同改变垂直投影。左右目标仍保持“机身左边目标投向图像左侧”的符号关系。

目标处相机光学Z与标签距离不同，不能混用。例如当前0°、1.50m目标的机身水平标签是1.500m，而投影光学Z约1.155m；相机前后安装位置和射线起点不同，目标点还低于镜头。该投影Z只是渲染图像深度，不是机身射线标签。

## 后续判断

1. **可以进入数据更新准备**：新版本应以当前候选位置与实测K重渲染输入，同时继续用同一ABS机身射线定义独立计算标签；同一机身位姿和障碍下标签不需要为了相机变换而改角度、束序或起点。
2. 不要把本批9个检查场景直接当成训练集合。完整准备前，给`prepare_d435i_ray_adaptation_data.py`增加最小显式相机参数入口或独立候选配置，保留默认几何；保持整场景train/validation/test隔离。当前底层生成器已有显式位置、俯角、K和原生渲染选项，本次采用这些函数及现有可见性逻辑，没有改生成器代码。
3. 当前候选的未知偏航/侧倾、玻璃参考至实际光学中心偏移，以及高度估算误差仍会改变投影；±45°束目标在该视场下完全不可见，训练无法恢复不存在的图像信息。后续数据应保留该可见性标签，不用拉伸或改射线合同。
4. **本次小批检查不需要机器人**。若要开始有物理意义的模型适配训练，下一项最小实机工作是相机按当前安装固定、Go2静止不动时，用中心及左右已知平整目标记录同步深度/IR、CameraInfo，并从base_link射线起点量到目标表面；同时量取相机安装偏航/侧倾。这样验证候选外参与机身距离基准，不涉及控制或运动。

本批没有补洞、模型推理、训练或控制器改动。所有渲染进程均已正常退出；仅本地离线生成样本与图表。
