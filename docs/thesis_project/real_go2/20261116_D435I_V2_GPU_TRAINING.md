# 当前安装v2：一次4轮GPU训练

## 训练前固定计划

用户授权本机训练一次。2026-11-16，RTX 4060 Laptop 8GB，abs环境PyTorch 2.0.1+cu118。只训练射线网络，不访问设备，不运行ABS策略或部署权重。

数据：`logs/real_go2/20261116_d435i_ray_adaptation_data/adaptation_v2_current_mount`，train/validation/test为840/180/180位姿、clean/masked配对。新test仅在模型选定后评价；其布局未参与前轮选模，但掩码来源仍复用，不能称独立实测验证。

从medium开始，layer4_fc、4轮、batch32、lr1e-4、AdamW、seed1、num_workers0、cuda:0。保留原近障加权损失与数据，不扩大轮数，不搜索参数。旧默认选模保留，显式使用新的visible_near选模选项。

选模规则在运行前固定：
1. 总体近障高估≥0.5m数量、远处低估≥0.5m数量、近障高估P95均不差于本批medium验证基线；同时画内近障高估数量和P95不差于该基线。
2. 合格轮次按画内近障高估数量最小、画内近障P95最小、总体MAE最小的顺序选择。
3. 无合格轮次就如实报告未选中，不追加训练；test不运行。
4. 选中后仅对medium和选中模型作一次固定test评价，分画内/画外报告。画内指射线交点在图像内，不自动保证未遮挡或masked输入有有效测量。画外完全不可见仍是能力边界。

输出目录：`logs/real_go2/20261116_d435i_ray_adaptation_data/training_runs/d435i_v2_medium_visible_near_gpu_20261116`。保留best、last及manifest，默认现场入口不改。训练后补充结果与退出状态。
