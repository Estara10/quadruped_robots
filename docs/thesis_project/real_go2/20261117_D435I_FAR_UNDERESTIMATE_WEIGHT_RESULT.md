# D435i远障低估损失权重单因素对照（2026-11-17）

## 结论

在上一轮近障补充训练的基础上，只把远障低估损失项由 `false_danger_weight=0` 改为 `0.5`，其余全部冻结，另开运行目录训练60轮。既定选轮规则同样选中第3轮，因此本轮是同一批数据、同一随机种子、同一数据顺序下 **epoch3 对 epoch3** 的单因素比较。

结果是一组明确的取舍，不是全面改善：

- **远障过度低估下降**：输入—射线记录口径 2232/3522→1986/3522（63.4%→56.4%）；位姿—射线配对口径 1149/1761→1018/1761（65.2%→57.8%）。
- **可见近障高估小幅反弹**：52/916→65/916（5.7%→7.1%），可见近障P95 0.530→0.602m，最大值3.698→3.801m。仍好于epoch13（88/916、0.774m、4.762m）和medium。
- **总体MAE改善**：0.988→0.922m，但近、中组变差，远组变好；仍差于epoch13的0.791m。

该权重没有让新模型同时守住上一轮的近障优势并追上epoch13，因此**不足以作为替换上一轮epoch3候选的理由**；可作为“远障更保守”的备选权重，是否进入静态实机只读观察应由独立评价集决定。本轮只评价参与训练和选轮的组合验证集，未读取最终留出集，不构成独立测试、实机精度或控制结论，权重未接入部署。

## 唯一改动与损失语义

训练器 `scripts/finetune_mujoco_ray_pred.py` 的 `weighted_ray_loss`：

```text
weights = 1 + near_weight * clamp((1.5 - target_m) / 1.4, 0, 1)
          + false_safe_weight * 1[target_m <= 1.5 and pred_m > target_m + 0.5]
          + false_danger_weight * 1[target_m >= 3.0 and pred_m < target_m - 0.5]
loss    = mean(weights * (pred_log2 - target_log2)^2)
```

`false_danger_weight` 是**加在基础权重上的增量**，不是对基础损失的独立乘子。由于远障低估条件要求 `target_m >= 3.0`，此时近障项必为0、近障高估项互斥，命中行的总权重为 `1 + 0.5 = 1.5`，即**基础权重提高50%**。这与任务给定语义一致，故本轮取 `false_danger_weight=0.5`，未改阈值（1.5m / 3.0m）、0.5m判据或损失形式。该值是本轮预先固定的实验选择，不宣称最优，未扫描其他权重。

需要如实说明的副作用：该改动同时把远障行上的总权重从1提到1.5，整体损失量级随之上升，且没有做归一化。按上一轮epoch3自身在组合验证集上的预测估算，平均权重由1.394升到1.582（约+13.5%），在 `grad_clip=1` 下有效步长可能随之变化。因此本轮隔离的是“该权重取0.5”这一整体改动，不能把收益单独归因于“重加权”而不含损失尺度变化。

## 五个主要问题

**1. 远障过度低估是否下降。** 是。记录口径 2232→1986（减少246条，−7.0个百分点）；配对口径 1149→1018（减少131个，−7.4个百分点）。配对逐例方向：远障对中1,371例绝对误差变好、291例变差、99例持平，平均预测向远移动0.196m。但仍差于epoch13（51.2% / 907）。

**2. 可见近障高估与P95是否反弹。** 是，小幅反弹。记录口径 52→65（+13，+1.4个百分点），P95 0.530→0.602m，最大值3.698→3.801m；配对口径 23→30（分母458）。反弹后仍好于epoch13（88/916、0.774m）和medium（211/916、1.265m）。

**3. 近、中、远有符号误差与MAE。** 均向远侧移动：近 +0.142→+0.173m、MAE 0.257→0.284m；中 +0.010→+0.102m、MAE 0.499→0.534m；远 −1.206→−1.010m、MAE 1.372→1.237m。即远障改善、近中代价，近组仍是平均高估。

**4. 各束与可见性分组是否有明显退化。** 可见性三组都略有退化，但没有一组被抹掉上一轮的改善：画内高估29→34（配对10→14/289），画外但表面可见23→31（配对13→16/169），完全不可见49→54（配对22→27/42）。逐束可见近障高估数为 −45° 5、−36° 6、−27° 1、−18° 6、−9° 13、0° 6、+9° 4、+18° 3、+27° 6、+36° 5、+45° 10，相对上一轮多数束增加1–4条，无单束异常跳变；+45° 边束仍最高（10/42，23.8%）。

**5. clean/masked是否一致。** 一致，未出现masked稳定恶化。记录口径近障高估 clean 61 / masked 58（上一轮52/49）；配对口径 masked−clean平均绝对误差变化 −0.0050m（上一轮−0.0098m），masked更好247对、更差253对；仅clean失败17对、仅masked失败14对。方向与上一轮相同，量级都在毫米级，不构成对masked输入的新依赖。

## 限制与下一步

- 上一轮的唯一建议未改变：**先建立未参与训练和选模、按新布局隔离的独立离线评价集，一次性比较medium、epoch13、上一轮epoch3与本轮epoch3**，再决定是否做相机/机器人静态只读观察。本轮的取舍说明，在独立评价集上仍应把可见近障高估作为门槛指标，不能只用远障比例或总体MAE选型。
