# 全网适配固定失败样本的几何与输入对应检查

## 结论

只检查既有失败报告中的三条固定“位姿—射线”，以及每条对应的 clean/masked 输入；没有重推模型、没有检查其他 checkpoint，也没有重新选模。三例的保存标签均与数据生成器几何计算、MuJoCo `mj_ray` 和原可见性 CSV 一致；按生成器原流程将渲染深度量化到毫米、再做中心采样后，重建的 clean 输入与保存数组逐格一致，按记录掩码重放的 masked 输入也完全一致。**未发现这三例存在射线标签错误、相机投影错误或160×90采样错位。**

但三类案例不能混为一谈：画内案例的关键目标像素进入模型输入；画外交点但墙面仍可见的案例只提供墙面的其他像素，射线命中点本身不在画内；完全不可见案例的目标几何没有任何图像像素，属于当前相机视野覆盖限制。可见目标仍出现大幅高估，说明几何/采样缺陷不能解释所有失败；这三例不足以确定网络泛化失败的具体成因。

## 固定样本和核对方法

样本 ID 从归档的`per_sample_per_ray.csv`、`summary.json`及原最终留出集`ray_projection_visibility.csv`读取，没有按文件名推断：

| 类型 | 固定样本 / 束 | 几何标签 | 原 medium → epoch13 输出（clean / masked） |
|---|---|---:|---|
| 画内 | `final_staggered_occlusion_pose015`，0° | 1.038 m | 1.360→2.845 / 1.369→2.611 m |
| 画外交点、表面可见 | `final_staggered_occlusion_pose044`，−45° | 1.352 m | 1.712→3.504 / 2.095→5.188 m |
| 障碍无可见像素 | `final_wide_wall_offset_pose017`，−45° | 0.842 m | 3.530→6.000 / 3.286→6.000 m |

预测值直接取既有逐样本 CSV，不是本轮推理。输入证据来自[可见性与投影记录](../../../logs/real_go2/20261117_d435i_fullnet_preparation/final_holdout_v1/ray_projection_visibility.csv)、[逐位姿数据记录](../../../logs/real_go2/20261117_d435i_fullnet_preparation/final_holdout_v1/data_records.json)、[交错遮挡场景](../../../logs/real_go2/20261117_d435i_fullnet_preparation/final_holdout_v1/scenes/final_staggered_occlusion.xml)和[宽墙偏置场景](../../../logs/real_go2/20261117_d435i_fullnet_preparation/final_holdout_v1/scenes/final_wide_wall_offset.xml)。标签核对使用每个姿态的11束：数据集保存标签、`compare_ray_pred.compute_geometric_ray_log`、可见性 CSV，以及对场景几何直接调用`mujoco.mj_ray`。按生成记录的当前安装候选重渲染原生480×270深度和分割，再调用现有中心采样函数。候选相机参数来自该留出集 summary：光学中心代理`(0.300, +0.020, +0.132)m`、下俯3°、内参`fx=fy=244.134, ppx=245.186, ppy=134.22`；这是生成候选，不是精确外参。

中心采样从480×270每隔3像素取一格中心（源像素`u=3x+1, v=3y+1`），形成160×90输入；没有缩放或插值。保存的 masked 图由对应记录中的实拍零值掩码移植到合成深度后，依照既有librealsense 2.58.4 mode 1等价实现补洞，残余未知置6 m。它是合成掩码增强，不是相机对该场景的真实空洞复现。

## 逐例结果

### 画内：pose015 的0°束

- 标签命中`right_behind`，1.037632 m。生成器、标签文件和可见性 CSV 的值相同；直接`mj_ray`为1.03763226 m。全11束中，生成器与保存标签最大差0，`mj_ray`最大差约`8×10⁻⁸ m`。
- 命中点投影为`(252.23, 167.95)`，在480×270画面内；该像素的分割几何 ID 与`right_behind`一致。目标几何有27,666个原生可见像素，其中3,066个落在160×90中心采样位置。
- 命中点最近的中心采样源像素为`(253,169)`，对应模型格`(84,56)`，该格分割仍为`right_behind`。渲染命中点附近深度约0.702 m，中心采样输入约0.668 m；采样位置偏离投影约1像素，深度差约3.4 cm，但没有采到别的几何体。因而“目标像素已进入输入”成立，“射线距离标签等于该像素光学Z”不成立，两者本来就是不同量。
- clean/masked中该命中格均为0.668 m；目标对应的3,066个采样格里9格曾被零值掩码覆盖并由mode 1填入，0格残余为6 m。mask未改变决定性命中格。
- 既有epoch13仍从clean的2.845 m、masked的2.611 m高估标签。这一例不支持“标签障碍因画内投影或采样而丢失”的解释；具体网络为何高估仍未知。

### 画外交点、墙面仍可见：pose044 的−45°束

- 标签命中`right_wall`，1.352026 m；生成器、标签文件和可见性 CSV一致，直接`mj_ray`差小于`2×10⁻⁷ m`。全11束同样通过上述核对。
- 射线命中点投影`(634.47,174.15)`，超出图像右边界；从相机光轴向右看约57.9°，而实测主点和焦距给出的右侧半视场约43.8°。但同一`right_wall`仍有46,853个原生可见像素，5,206个中心采样格，故“命中点画外”不等于“墙面全不可见”。采样保留了大块墙面，却不含标签所指的命中点像素；网络必须从可见的其他墙面区域推断该束距离。
- 该墙面目标区域中215/5,206个中心采样格被掩码置零后由mode 1填入；残余6 m格为0。clean/masked墙面采样深度中位数为1.211/1.214 m。掩码改变了部分输入，但没有消除可见墙面。
- 同一几何标签下，epoch13预测由clean 3.504 m变为masked 5.188 m；medium由1.712 m变为2.095 m。这个单例显示掩码会改变输出，不能推成总体因果；既有全数据配对分析仍显示clean/masked没有稳定的普遍恶化方向。

### 目标无可见像素：pose017 的−45°束

- 标签命中`near_right`，0.842338 m；三种标签计算相符，直接`mj_ray`误差小于`2×10⁻⁷ m`。
- 命中点投影`(841.13,249.38)`，明显在图像右侧之外，水平视角约67.7°。对盒体表面的投影采样范围最左仍约`u=779`，而图像最右像素为479；分割图中目标几何可见像素为0，160×90中心采样格也为0。因此这是目标完全在当前视场外，并非它进入原图后被中心采样漏掉，也没有像素证据可由补洞恢复。
- 对应clean/masked整幅输入仅有488格不同；目标几何区域无采样格，因而没有目标掩码、补洞或6 m占位格。该label是场景真实几何距离，但不是视觉输入可直接观测的距离。
- epoch13 clean/masked均输出6 m，medium分别为3.530/3.286 m。该例主要体现物理视野限制；不能用更多同类标签要求单目深度网络恢复不存在的图像信息。

## 判断和下一步

三例都**没有发现生成器或采样实现错误**。画内案例的关键几何既投影正确，也保留在采样网格中；部分可见案例的墙面大范围进入输入，尽管实际ray-hit点在视场外；完全不可见案例则没有任何目标像素，属于物理覆盖边界。补洞候选改变了前两例的一小部分/一部分可见面输入，未把这些区域变成6 m；第三例的掩码变化与目标无关。

因此，失败应分成两类理解：pose017属于当前视场无法直接观测的目标；pose015和pose044有目标几何信息进入输入仍高估，属于模型从当前图像特征预测几何射线的泛化/映射问题候选，不能归因于数据对应错位。两例不足以确认具体网络根因。

**唯一建议的下一步：**在下一轮训练前，离线把ray-hit目标按“画内且命中像素可见 / 画外但同一障碍表面可见 / 目标完全不可见”分组评价，并将完全不可见明确作为视野能力边界单列；完成条件是近障高估指标能分别反映可学习的可见失败和物理不可见束，不把后者混成模型精度。无需机器人。
