# 站立静态197.3cm双模型对照

> 收尾更正：操作者随后报告“趴下了”，尚未确认是采集前还是采集后。文件名沿用原记录，采集姿态目前待核实。下文2.320m仅为站立几何假设下的参考；不能据本组判定站立实测性能，也不能直接用地面拟合结果替换固定外参。原始数据及模型输出保留。

操作者报告Go2站立，镜头附近至前方柜面197.3cm；精确测尺起点和柜面朝向未额外确认。只采相机，无机器人控制。

使用Orin既有librealsense 2.51.1，序列号238322070866，480×270@60，深度＋IR1，投射器开启，自动曝光，激光功率150。复用历史采集程序，预热3秒、采集10秒，仅保存第0、240、480帧的原始深度、SDK mode1补洞深度和IR1，其余帧仅保存统计。未使用ROS、DDS、VINS或控制器。

## 结果

600帧，实际59.91Hz。原始中心像素全段中位数1.972m，对人工报告1.973m相差约1mm；原图平均零值6.29%。此为本次测点的一致性，不是完整相机精度标定。

两个模型分别对相同3张代表帧推理，并非连续600帧推理。输入使用SDK mode1补洞、残余未知填6m、中心采样、clip和log2三通道，复用现有观察器函数。

| 代表帧 | 相机中心深度m | 近障补充epoch3 0°束m | 原300轮epoch13 0°束m |
|---|---:|---:|---:|
| 0 | 1.992 | 0.906 | 1.093 |
| 240 | 1.952 | 0.910 | 1.103 |
| 480 | 1.972 | 0.885 | 1.096 |
| 三帧预测中位数 | — | 0.906 | 1.096 |

在柜面竖直、近似正对机身、卷尺线近似沿光轴的假设下，当前安装x=0.300m、俯角3°，射线起点x=-0.050m，机身0°束参考约为1.973×cos(3°)+0.350=2.320m。它是近似换算，不是独立精确标签。

两模型都明显偏近：近障补充epoch3约低估1.414m，epoch13约低估1.224m。本次真实柜前样本epoch13较接近，但两者都未恢复合理的0°机身距离；不能依据仿真近障排名宣称真实距离已改善。此结果描述严重低估，不能直接等同于闭环安全或碰撞表现。未评价其他束准确性。

IR标记确认中心测点落在柜面。没有修改相机标定、训练或部署权重。最初编译未找到默认SDK头文件，尚未打开流；指定现有/opt/ros/foxy的SDK路径后完成采集，未安装软件。
