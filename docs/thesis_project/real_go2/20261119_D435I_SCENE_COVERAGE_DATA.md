# 前置 D435i 射线训练场景补充 v1（仅数据准备）

## 目的与结论

针对约 1 m 正对宽墙输入覆盖不足，新增了一批按完整 MuJoCo 布局隔离的 clean/masked 射线训练数据。本批只生成并检查数据；没有训练模型、运行策略、连接设备或改部署配置。

此前约 0.995 m 仿真墙对照中，相机中心深度与几何输入匹配，但 epoch13 和近障 epoch3 的 0° 输出均明显偏远。两次训练虽包含相近的距离标签，近距离宽平墙占中央图像的样本却很少。本批有 60 个正对宽墙训练姿态；其中 32 个相机到墙的水平距离落在 0.7–1.3 m。固定模型输入中央 50×60 区域内，墙深度落在 0.7–1.3 m 的平均像素比例为 99.42%，均匀度检查均值为 100%。这是输入覆盖结果，不是网络精度结果。

## 固定定义和生成流程

- 相机候选：左 IR 前玻璃代理相对 `base_link` 为 `(0.300, +0.020, +0.132) m`，下俯固定 3°，base 高度固定 0.348 m。偏航/侧倾按零假设；玻璃参考点、相机光学中心偏移及 base 高度均非精密外参。
- 深度相机：实测 `480×270`，`fx=fy=244.134`、`ppx=245.186`、`ppy=134.22`。所有场景渲染原生深度后采用既有 `(3i+1,3j+1)` 中心采样得到 `160×90`；原始参数和布局写在新目录的 `dataset_plan.json`。
- ABS标签合同未改：11 束按 `−45°…+45°`、每束 9°，索引0为−45°；水平 `base_link` XY 几何射线从 `(-0.05,0) m` 出发，距离裁剪在 `0.1–6 m`。标签从场景几何生成，不使用图像中心深度或网络预测。
- clean 输入与 masked 输入逐位姿成对。masked 路径复用现有真实零值掩码增强、mode 1 补洞实现和残余未知填 6 m 候选；这些掩码增强不是传感器物理仿真，6 m 也不表示测得空旷。
- 增加 `--scene-coverage-v1`，仅为这版布局增加逐布局位姿范围和 `no_hit`/`forward_clear` 接受类型。旧模式默认值和既有数据没有重生成或覆盖。

## 几何和数据检查

- 解析墙面检查：墙前表面 `x=1.60 m`、ABS 0°射线起点 `x=−0.05 m`，故几何标签为 1.65 m；现有标签代码输出 1.64999998 m。相机中心前向墙距为 1.30 m，两个距离基准在记录中分开。
- 正/负束探针通过：机身 `+y`（左）正角束投向图像左侧，负角束投向右侧；侧物探针保持中央 `−18°…+18°` 无命中，外侧束命中侧物。
- 空场景探针的11束均为6 m；全部训练数据也通过有限性、`160×90` 尺寸、`0.1–6 m`输入范围、11维标签和clean/masked同标签检查。完整布局隔离审计通过：310/160/150个位姿，分别为620/320/300张输入图。
- 宽墙中央覆盖：60个正对墙位姿的相机到墙距离约0.462–1.711 m，包含近/远端；其中32个在0.7–1.3 m。该32例中央50×60模型输入区域的中位深度为0.707–1.263 m；区域内0.7–1.3 m像素比例均值99.42%。其余样本拓展近、远端范围。
- 重要标签语义：ABS当前标签代码以所有障碍几何的 XY 占地算水平射线，不按障碍高度裁切。本批家具的抬高桌面/座面因此仍可能遮住地面 XY 标签；409条命中束的 base 高度3D射线与 XY 标签相差超过2 cm。它们是两种几何语义的差异，不是补洞或图像采样错误。保留既有标签合同；如后续需要表达桌底净空，应单独审阅标签合同，不能把本批称作高度感知标签。
