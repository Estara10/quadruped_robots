# Go2 实机操作手册

每次处理 Go2 实机相关任务前完整读本页。计划续接、分析日志和写执行器提示词也适用。当前进度查[实机记录索引](README.md)和[当前项目状态](../CURRENT_STATE.md)。本页是实机操作入口，实验进度以对应记录与实际文件为准。

## 上手前

1. 确定本次是离线分析、现场只读采集，还是用户安排的实机运动。写清要回答的问题和完成条件。
2. 打开对应的既有记录或原始数据，核对支架、模型、机器人姿态、测量起点及已完成项目。能用已有数据回答就直接复用。缺少的量单独记下，只有它会影响当前结论或下一步时才安排补采。
3. 需要联网时，先在电脑用 `ip -br -4 addr` 和 `ip route get 192.168.123.18` 确认实际接口。换盘后的已用配置为电脑 `enp8s0 / 192.168.123.99/24`，Orin 为 `192.168.123.18`。旧命令含 `enp7s0`，按现场查询结果选接口。网络恢复办法见[实机记录](README.md)。

## 现场操作

- **相机和状态只读。** 按本次任务选入口，确认同一相机只有一处采集程序占用。记录支架或模型是否变动、站立或趴伏、场景及关键数据目录。相机光学深度和机身射线距离分别记录，做误差对照时统一方向和起点。[D435i 射线观察说明](../../../scripts/go2_depth_ray/README.md)
- **人工遥控配合采集。** 由现场操作者确认就位、控制运动和停车。开始记录后告知操作者。收到「停止」时立即结束本次采集，按本次分工确认机器人已停。只读采集程序无法停车。记录机器人移动期间采用的控制方式。
- **由电脑发运动命令。** 依当次任务授权及项目实机阶段执行。先确认场地、遥控接管及停止方式，按对应入口逐步运行。完整 ABS 低层控制目前仍待验证，原生运动和机载只读联调的结果分别记录。[Go2 原生终端现场命令](../../../scripts/go2_native_motion/FIELD_COMMANDS.md)

## 已有记录如何复用

| 项目 | 已完成内容与使用范围 |
|---|---|
| 静态挡板 | 正前方挡板、换支架后的侧前方挡板放入与移走均已有记录。查测量起点和支架版本，再引用对应结论。 |
| 动态靠墙和开阔对照 | 两组靠墙和一组开阔的采集与时序分析已完成。可分析报近和回升过程。首次持续报近时的同步实测墙距未记录。[时序总结](../../../logs/real_go2/20261120_orin_motion_bumlW7/wall_open_timeline/SUMMARY.md) |
| 椅子与自行车 | 指定的两组采集与时序分析已完成。可引用各方向报近和回升的表现。[时序总结](../../../logs/real_go2/20261120_orin_motion_bumlW7/chair_bike_timeline/SUMMARY.md) |

实机采集、离线复核和控制闭环分别标记。读数随场景变化、距离精度和实际避障表现各自需要对应的证据。

## 收尾和更新

1. 确认本次启动的相机、状态订阅、采集器及辅助进程已退出。先确认进程归属，再清理。
2. 保存关键原始日志、少量代表图或必要视频，以及简短结果。将结果入口补到[实机记录索引](README.md)或[当前项目状态](../CURRENT_STATE.md)，写清做完的项目、缺失量及清理状态。
3. 下次续接优先从已归档的结果往下走。只有出现新的具体问题，且旧记录无法回答时，才提出复测。
