## 最终目标

**通过分析现有问题，建立一批符合机器人感知和运动能力的高难度地图，找到合适的退出阈值X和最小保持时间H，使切换约束在困难场景中产生实际任务收益。**

原因分析服务于地图设计和参数研究，不要求排清所有失败原因后才进入下一步。允许讨论进入阈值E，但候选方案需单独标记，不能覆盖原A/B/C/D。

接受频繁切换是正常现象。依据安全完成、到达、碰撞、超时、推进和耗时评价收益；切换次数和Recovery占比用于解释，不保证某组优于A。
