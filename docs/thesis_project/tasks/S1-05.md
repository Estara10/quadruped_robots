## 工作一：碰撞定义与仿真侧累计记录

- 核对现有 MuJoCo 接触来源、机器人与地面/障碍的分类，以及当前快照丢失物理步的原因。
- 正常脚掌接地不算障碍碰撞；机器人与障碍的接触、机身或非足部与地面的异常接触应分别保留，不能混为正常接地。写清自碰撞和无法分类接触的处理。
- 优先在仿真物理步侧检查接触并累计或锁存事件，让采集器漏采快照时仍能发现期间发生的碰撞。复用现有机制，不建设通用事件平台。
- 定义事件去重：持续接触不能按每个物理步都计为一次新碰撞。给出简单的接触开始/结束规则；无法可靠统计独立次数时，只报告是否发生和已支持的持续区间。
- 事件至少关联仿真实例/时间段、物理步或等价序号、仿真时间、接触对象分类及必要的具名对象；通过 run 上下文明确绑定本次来源。
- 明确累计器的起点、重置、连续检查范围和终局读出。启动期、运动期、清理期分开，不能把运动前后的接触计入运动指标。
- 接入终局处的累计快照及保存路径，避免到达时漏掉最后一个物理步的事件。不能可靠确定边界时保留区间或 UNKNOWN。
- 只有来源、运动覆盖和结束读出均可信，且累计事件为零时，才能报告该定义下未发生碰撞。不能仅凭无 safety veto、无采样接触或累计字段为零推断无碰撞。

## 工作二：简单、可解释的跌倒判定

- 核对实际位姿来源、姿态表示、坐标系、高度基准与单位。
- 基于机身姿态、高度及持续时间制定最小判定规则，说明条件如何组合；避免把瞬时姿态变化或启动站立过程误判为跌倒。
- 持续时间使用有效仿真秒，明确相等边界、计时起点、条件解除及缺失/无效样本的处理。缺帧不能被当作已连续满足条件的证据。
- 判定字段区分原始观测、候选跌倒条件与确认事件；至少保留触发依据、来源周期和时间。
- 数值仅为本次诊断规则，说明选择理由和适用场景；正式阈值由 S6 冻结。本任务不进行参数扫描或训练。
- 若仅在策略频率上检查，说明能检测持续跌倒而不能保证发现两帧间的所有瞬态。不要声称得到超出观测能力的完整覆盖。

## 工作三：终局、事件和数据有效性分别记录

- 在既有 run 合同中补充到达、跌倒、仿真时间超时、碰撞终止、人工中止和系统安全中止的直接来源与判断规则；墙钟保护时限不能冒充仿真超时。
- 说明本次诊断中碰撞是否立即终止，以及同周期多个条件成立时的优先级。优先级须在运行前写明，保留全部已观测事件，不以单一终局字段覆盖碰撞事实。
- 采集故障、session 混流、来源冲突或终止载荷缺失属于数据有效性问题；与任务如何结束分别保存。无效数据不能写成成功，真实任务失败也不能仅因失败而排除。
- 保留 S1-04 的完整终止快照和唯一终局记录；安全中止可能停止产生策略帧，应关联已有外部安全事件及最后可信周期，不伪造终止策略帧。
- 指标边界包含可信终止周期，排除清理尾段。给出碰撞/跌倒状态、覆盖范围、终止原因和相应证据引用。
- 停止请求、策略停止确认、进程退出和 MuJoCo 命令消费是不同事实，分别表述。最后两项无法观测时保留 UNKNOWN，不扩张为命令确认系统。

## 工作四：最小验证

允许且要求对直接修改部分做针对性离线检查、必要构建及少量非正式仿真。

离线验证优先调用生产判定、记录和收尾路径，至少覆盖：

- 正常足部接地排除、障碍接触识别和连续接触去重；
- 采样间发生的碰撞仍保留于累计结果；来源变化、重置或覆盖缺口不能得出无碰撞结论；
- 正常站立/姿态变化、满足与未满足持续时间、阈值相等及无效时间/观测；
- 同周期多种终局条件、清理事件不覆盖运动终局、故障收尾仍清理；
- 终止时事件与快照落盘，缺失关键记录时分析器拒绝对应完整指标。

离线检查通过后，先写明短诊断设置、预期核验内容和运行上限。最多做两次必要短仿真：一次正常运动验证记录与收尾，一次受控接触/姿态验证检验仿真来源到结果的链路。可在同一短诊断中覆盖多个条件，不要求每个分支单独运行。

受控接触/姿态可在独立仿真检查中完成，不必强迫 RL 机器人撞击或跌倒；明确记录人为设置，不能用于策略效果结论。不得改动模型输出、策略接口或关闭安全检查。实际来源未验证的分支如实标记，离线结果不冒充运行证据。
