# S1-06 — 部署通道排列离线核验

**状态：COMPLETE — Director 有条件通过。**

Director 接受的范围为生产 observation/order helper 的唯一标记值离线检查，以及对 Agile、inline Recovery 和独立 Recovery 状态类实际动作转换源码的核对。此结论不表示私有动作成员已被直接调用，也不表示运行时接触接口取值已验证。足接触来源限制和直接调用范围见执行报告。

## 目标

对实际部署通道转换做离线核验：actor 动作、关节位置/速度、默认关节位置与偏置、前一动作及足接触；分别检查 Agile 和 inline Recovery。使用每通道可区分的具名标记，并调用控制器生产路径中的转换函数。不得由此推断模型推理、仿真或实机接口已运行验证。

## 范围

- 只读复核当前轻量权威文档和现有动作顺序证据。
- 只做直接相关的离线核验及控制器组件构建。
- 若发现映射错误，保留现状并报告 Director；本任务不自行修正运行时映射。
- 不训练、不运行模型推理/仿真/实机，不提交 Git，不启动 S2。

## 验收项

1. 输出策略 FL、FR、RL、RR × hip/thigh/calf 到控制器 FR、FL、RR、RL 具名关节的逐项对应。
2. q、dq、默认位置、bias 和前一动作的转换/字段关系由生产函数及状态构造路径支撑。
3. Agile 与 inline Recovery 的策略动作回到控制器关节顺序的路径分别核对。
4. 足接触核对状态接口具名来源和转换；证据不足处明确标 UNKNOWN。
5. 报告运行方式、检查结果、证据文件、遗留缺口，并更新任务引用和 CURRENT_STATE。
