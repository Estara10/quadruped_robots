## 几何定义

起点(0,0)、目标(7,0)，检测有限线段而非无限直线。障碍实体水平投影与线段内部有正长度交集才算直接阻挡，切点/仅贴边不算。不只检查障碍中心，也不把附近但未交线的障碍算作直线阻挡。起点、目标附近继续留出安全空间。

## 实施顺序

1. 保存旧 layouts.json、五张预览和五份XML到本任务证据目录的 previous_layouts 子目录，保留旧身份。不得覆盖历史诊断证据；给新布局明确 revision，并记录原seed加确定性编辑，不能声称重新用原seed随机生成。
2. 仅调整01/02/03规定障碍，更新当前 layouts.json及版本说明。04已知边界超出0.0564m继续记录，默认不调整，05不变。
3. 从新坐标重生成五张俯视图，标明起点、目标直线、阻挡障碍和保留通道。图、JSON与XML一致。通道节点只作几何约束，不输入控制器。
4. 更新01/02/03 XML及场景目录身份/编译指纹。检查04/05无意外变动，ray writer和collision authority仍使用同一障碍集合，旧记录按保存的身份解释，不套用新地图。
5. 每张地图输出直线相交障碍编号及实际交线范围，至少三张通过。检查通道宽1.10m、起终点净距、障碍边界和非重叠，完成生产MuJoCo加载检查及必要增量构建。
6. 新布局在运行前冻结。01/02/03各允许一次有效A短诊断，E=-0.05、目标(7,0)、到达半径0.5m、仿真运动20秒、墙钟120秒、健康到达后站立5仿真秒。04/05不需重跑。合法失败保留，禁止为到达而调整障碍或重跑。基础设施失败修复后可补证，保留INVALID历史。
