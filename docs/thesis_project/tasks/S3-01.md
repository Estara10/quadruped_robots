## 冻结规则

以 SWITCH_CONTRACT.md 为准：

| 当前状态 | 条件 | 下一状态 |
|---|---|---|
| Agile | RA >= E | Recovery |
| Agile | RA < E | Agile |
| Recovery（A） | RA < E | Agile |
| Recovery（A） | RA >= E | Recovery |
| Recovery（B） | RA < X | Agile |
| Recovery（B） | RA >= X | Recovery |

- A/B 共用进入阈值 E；B 满足 X < E。
- RA == E 从 Agile 进入 Recovery；RA == X 在 B 中不退出。
- 转换周期即采用新模式动作。B 无 hold，不设置保持计时器。
- 本轮功能诊断数值 E=-0.05、X=-0.08；X 仅为明确的诊断候选，不是正式论文参数，S6 再选择冻结。
- 阈值区间内模式依赖上一状态；不得用每周期无状态选择替代滞回。
- 无效 RA、生命周期重置和安全路径沿用共同合同。
