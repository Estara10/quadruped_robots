## 运行规则与停止点

- 严格按 A、B、C、D 顺序，每组最多一次场景运行；前一组完成清理并核对进程退出后才能开始下一组。
- 使用普通运行和原跌倒规则；禁止 `--startup-recovery-observation-s` 及其他启动低高度延期。
- 合法碰撞、跌倒、超时、安全终止均作为结果保留，不为到达、触发 Recovery 或获得有利结果重跑。
- 准备失败、基础设施失败、来源混流或无法确认清理时，保留 INVALID/未运行状态并停止后续组。
- 记录实际初态和组间差异；相同准备流程不代表严格重放。
- 每次结束先关闭 MuJoCo，再结束本次 controller、ROS launch、RViz、采集器、停止发布器和辅助进程；确认进程来源后清理并核对退出。
