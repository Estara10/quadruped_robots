## 五类几何结构

1. 单侧绕行：随机选左侧或右侧。
2. 连续交替绕行：参考结构包含多个左右方向变化。
3. 错位通道口：多个位置不同的障碍开口。
4. 多路线分叉：至少两条分别通过不同通道或绕过不同障碍侧的可行路径，并各自通过完整包络检查。
5. 不规则障碍群：随机布障后以实际几何检查连通，不预设三次曲线通道。

生成使用有界重采样；失败时记录最后拒绝原因。不规则障碍群的连通检查和其他结构的每条参考路径均用旋转箱体/圆柱实际二维轮廓、有限网格搜索和连续路径复核。
