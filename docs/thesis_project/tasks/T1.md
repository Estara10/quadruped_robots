## 5. 指标与选取原则（运行前确定）

优先判断数据可用性；以实际证据足够的指标选参。任务窗口、全采集窗口及收尾窗口分开。

1. 任务与安全：ARRIVED、碰撞终止、跌倒终止、超时分别计数；另列足端撞击、安全中止、UNKNOWN、INVALID及分母。到达率与具有完整安全证据的到达分别报告，不能把两者混称成功率。
2. 切换稳定性：每run总切换、0.5秒短反向切换及每分钟有效任务时间的频率、相邻切换间隔；分母和覆盖同行列出。失败早停的低切换数不视为改善。
3. 代价：到达运行的耗时、路径/速度、Recovery总占比和单次驻留；失败运行终点距离及停止时间另外列出，不将超时当完成时间。关注是否长期不退出Recovery。
4. 机制：进入/退出边界与本档阈值一致。无Recovery不等于该阈值更优；末端Recovery右删失与数据缺失分开。

先排除表现明确被其他候选同时压过的档位，再综合判断“任务完成与安全未明显变差、短反向减少、Recovery占比和到达耗时不过度增加”的候选。小样本不设事后显著性承诺，不把两次重复中的小差异当定论，不用任意加权总分掩盖权衡。无法区分则保留2–3档继续验证；明确存在安全/任务代价的方案不能凭切换最少获胜。
