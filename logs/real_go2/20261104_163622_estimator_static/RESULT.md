# Go2 Estimator 趴伏静止只读观察

日期：2026-11-04。用户确认机器人已开机、连接并稳定趴伏后授权观察。

针对问题：真实LowState输入下，现有Estimator能否初始化并持续输出，静止速度是否稳定。

## 操作

使用 enp7s0（192.168.123.99/24）、domain 0，独立观察器运行30秒，仅订阅rt/lowstate。没有发送LowCmd、调用模式切换、加载策略或启动ROS控制器；未要求机器人运动。未修改代码、模型、仿真配置或任务状态。

## 结果

- 进程退出码0，记录5998行，时间0.015–30.000秒。全部输入、估计有限，全部样本新鲜；重复样本0。
- LowState平均接收频率约 499.93 Hz（由首末接收序号/时间计算）。样本时龄平均1.121 ms、最大3.701 ms。
- Estimator更新周期除首次等待首帧外：平均 5.0000 ms，范围 4.6498–5.4819 ms。首次记录周期15.008 ms包含等待首帧；固定算法dt仍为5 ms。
- 原始足力FR/FL/RR/RL为15/15/14/14，阈值1下四路全程接触；不据此认定接触误判或调整阈值。
- 四元数范数约1，姿态记录稳定。静态观察不足以独立验证全部关节映射、单位和动态坐标语义。
- 为描述初始化后的表现，统计2–30秒：机体系vx/vy/vz均值约[-0.00300,-0.00049,-0.00433] m/s，标准差约[0.00085,0.00115,0.00108] m/s；速度模平均0.00550 m/s、最大0.00885 m/s。
- 2–5秒与27–30秒速度均值分别约[-0.00318,-0.00035,-0.00457]与[-0.00302,-0.00034,-0.00425] m/s，未见起末均值明显扩大。完整初始化数据保留在原CSV中，未删除。

## 结论与限制

完成本次静止观察：真实输入下估计持续有效，存在毫米每秒量级非零静态偏差，未见持续发散。结果仅支持本姿态下的静态通路和数值表现，不证明动态速度精度、原生服务关闭时表现，也不解决Recovery仍优先读取旧odom的问题；不能据此启用项目低层策略。
