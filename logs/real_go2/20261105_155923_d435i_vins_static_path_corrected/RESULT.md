# D435i双目＋IMU VINS首次静止检查

2026-11-05。接入候选经用户同意后，由主助手执行相机-only检查，未连接或操作Go2。原先由主助手引入的运行标定路径错误已修正，本目录为修正后检查；先前失败目录独立保留。

## 配置和范围

固定使用准备好的CPU VINS及候选参数。运行配置仅将输出目录改成本次目录，保持cam0_calib/1相对文件名并复制左右标定文件；未调参。左右红外640x480@15Hz，gyro200Hz、accel100Hz，enable_sync=true、unite_imu_method=2；深度、RGB关闭，投射器保持默认。ROS域42。

给用户指令是保持相机静止，未要求移动。现场是否完全无扰动没有独立测量，因此以下仅是静止指令下的输出统计，不是精密真值误差。

## 结果

运行35秒，约2.5秒日志出现Initialization finish!，持续发布跟踪图及两种里程计。
- 左右各510帧，接收约15Hz，最大间隔约70.6/69.2ms；记录中510条左图均有完全相同header时间的右图。这证明本次接收数据配对良好，不等于独立证明传感器完全硬件同步。
- 合并IMU6795条，约199.98Hz，最大接收间隔11.37ms，记录数值有限且header递增。此前独立gyro/accel已验证，本次补充确认method2合并通路。
- image_track398帧，约11.71Hz，最大间隔486ms。
- 优化odometry240条，约7.43Hz，最大间隔495ms；IMU传播6464条，约199.93Hz，最大间隔11.19ms。两种输出数值均有限、header递增，frame_id=vins_world，child_frame_id=camera_imu_optical_frame。
- 从采集第5秒起：优化速度模均值0.00270m/s、最大0.01507m/s，位置相对该段首帧最大偏移0.00141m；传播速度模均值0.00588m/s、最大0.02675m/s，最大位置偏移0.00454m。body速度分量、净位移详见static_metrics.json。

这支持基础输入和静止运行已接通；不能证明运动时的尺度、方向、延迟、外参或速度准确性。外参/时间偏差的在线估计在静止缺少激励，本次初始化成功不代表它们已正确收敛。

## 样图与已知限制

已查看feature_track.png：双目图上存在特征标记，但很多位于投射散斑和强反光区域，场景还有近处桌面及上部区域。不能从静止图就判断这些点可支持移动时的世界固定特征。后续VIO应核对投射器选择，不能直接把静态低漂移视作动态可靠。相机IMU标定缺失/default参数的已知限制未解决。

## 收尾故障

35秒后先向VINS发送SIGINT，日志在signal_handler之后报terminate called without an active exception，退出码-6；这是停止阶段异常，不是正常退出。相机SIGINT后退出0。cleanup.json记录PID、信号和退出码；按已知可执行路径检查无残留。未创建ROS CLI daemon。现场运行阶段已取得的记录保留，但不能声称全流程通过。
