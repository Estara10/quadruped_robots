# MuJoCo Go2 场景说明

坐标约定：

```text
机器人朝 +x 前进
y > 0 = 左侧障碍
y < 0 = 右侧障碍
中线 = 靠近机器人正前方路径，最容易触发避障
```

运行格式：

```bash
cd ~/quadruped_robots
MUJOCO_SCENE=场景名.xml ./scripts/launch_abs_obstacle.sh
```

## 推荐测试顺序

### 1. 平地直线

```bash
MUJOCO_SCENE=scene_flat.xml ./scripts/launch_abs_obstacle.sh
```

看：

```text
[EVAL] robot=(x,y) yaw=...
[GOAL] ... path_err=... path_on=1
```

目标：中途横向偏移尽量小；无 recovery。

### 2. 标准避障

```bash
MUJOCO_SCENE=scene_obstacle.xml ./scripts/launch_abs_obstacle.sh
```

看：

```text
[RA-REC] 进入恢复
path_on=0
[RA-REC] 退出恢复
path_on=1
```

### 3. 左右均衡测试

```bash
MUJOCO_SCENE=scene_test2.xml ./scripts/launch_abs_obstacle.sh
```

看有没有明显只向某一边绕。

### 4. 难一点的中线障碍

```bash
MUJOCO_SCENE=scene_rand_03.xml ./scripts/launch_abs_obstacle.sh
```

或：

```bash
MUJOCO_SCENE=scene_rand_08.xml ./scripts/launch_abs_obstacle.sh
```

这两个更容易触发 recovery。

### 5. 暂时不建议作为基础验证

```text
scene_terrain.xml
scene_slope_obstacle.xml
scene_side_slope.xml
```

这些用于后续鲁棒性评估，不适合当前真机迁移前基础验证。
